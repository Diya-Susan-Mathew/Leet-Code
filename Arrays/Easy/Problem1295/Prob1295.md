# LeetCode 1295: Find Numbers with Even Number of Digits

## Problem

Given an array of integers `nums`, count how many numbers contain an even number of digits.

## Java Solution

```java
class Solution {
    public int findNumbers(int[] nums) {
        int evenCount = 0;

        for (int i = 0; i < nums.length; i++) {
            if (nums[i] >= 10 && nums[i] <= 99) {
                evenCount++;
            } else if (nums[i] >= 1000 && nums[i] <= 9999) {
                evenCount++;
            } else if (nums[i] == 100000) {
                evenCount++;
            }
        }

        return evenCount;
    }
}
```

## Explanation

### 1. Initialize the counter

```java
int evenCount = 0;
```

This variable stores how many numbers have an even number of digits.

### 2. Traverse the array

```java
for (int i = 0; i < nums.length; i++)
```

The loop checks every number in the array.

### 3. Check the number of digits using ranges

```java
if (nums[i] >= 10 && nums[i] <= 99) {
    evenCount++;
} else if (nums[i] >= 1000 && nums[i] <= 9999) {
    evenCount++;
} else if (nums[i] == 100000) {
    evenCount++;
}
```

- `10` to `99` contains two-digit numbers.
- `1000` to `9999` contains four-digit numbers.
- `100000` is a six-digit number.

Each of these has an even number of digits, so the counter is increased.

**Note:** This range-based solution relies on the usual LeetCode 1295 constraint that each number is between `1` and `100000`. If the allowed range changes, the checks may need to change too.

### 4. Return the count

```java
return evenCount;
```

Returns the total number of values with an even number of digits.

## Example Walkthrough

```text
nums = [12, 345, 2, 6, 7896]
```

| Number | Number of digits | Even number of digits? |
|---:|---:|---|
| 12 | 2 | Yes |
| 345 | 3 | No |
| 2 | 1 | No |
| 6 | 1 | No |

Output:

```text

```

The numbers `12` and `7896` have an even number of digits.

## Complexity Analysis

- **Time complexity:** `O(n)` because each number is checked once.
- **Space complexity:** `O(1)` because only a counter and loop variable are used.

## Key Idea to Remember

Count numbers with 2, 4, or 6 digits. Under the problem's constraints, these are the possible even digit counts.

## Alternative Idea

You can also count digits for each number using a loop or convert each number to a string and check its length. Those approaches avoid writing a separate range for each digit count.

---

## Approach 2: Convert Each Number to a String

This approach converts each number to a string and checks the string's length.

### Java Code

```java
class Solution {
    public int findNumbers(int[] nums) {
        int evenCount = 0;

        for (int i = 0; i < nums.length; i++) {
            String str = String.valueOf(nums[i]);

            if (str.length() % 2 == 0) {
                evenCount++;
            }
        }

        return evenCount;
    }
}
```

### Explanation

1. Initialize `evenCount` to `0`.
2. Loop through every number in `nums`.
3. Use `String.valueOf(nums[i])` to convert the number to a string.
4. Use `str.length()` to count its digits.
5. If `str.length() % 2 == 0`, the number has an even number of digits, so increment `evenCount`.
6. Return `evenCount` after checking all numbers.

### Example

For `nums = [12, 345, 2, 7896]`:

| Number | String length | Even number of digits? |
|---:|---:|---|
| 12 | 2 | Yes |
| 345 | 3 | No |
| 2 | 1 | No |
| 7896 | 4 | Yes |

Output: `2`

### Complexity

- **Time:** `O(n * d)`, where `n` is the number of elements and `d` is the number of digits. Since the number of digits is bounded in this problem, this is effectively `O(n)`.
- **Auxiliary space:** `O(d)` for the temporary string, effectively `O(1)` for bounded-size integers.

## Comparison of the Two Approaches

- **Range-checking approach:** Checks whether each number is in a range corresponding to an even digit count (2, 4, or 6 digits under the problem's constraints).
- **String approach:** Converts each number to a string and checks whether its length is even. This is often easier to read and adapts more naturally if the digit constraints change.
