# Shuffle the Array

## Problem

Given an array:

```text
nums = [x1, x2, ..., xn, y1, y2, ..., yn]
```

Return the array in the shuffled order:

```text
[x1, y1, x2, y2, ..., xn, yn]
```

### Example

**Input:**

```text
nums = [2, 5, 1, 3, 4, 7]
n = 3
```

**Output:**

```text
[2, 3, 5, 4, 1, 7]
```

Because:

```text
x = [2, 5, 1]
y = [3, 4, 7]
```

We need:

```text
[x1, y1, x2, y2, x3, y3]

= [2, 3, 5, 4, 1, 7]
```

---

## Approach

The array contains two halves:

```text
nums = [x1, x2, x3, ..., xn, y1, y2, y3, ..., yn]
```

We need to place:

```text
x1 → result[0]
y1 → result[1]

x2 → result[2]
y2 → result[3]

x3 → result[4]
y3 → result[5]
```

So we can use **two separate loops**.

### First Loop

We fill the **even indices** of `result` with elements from the first half.

```java
result[i] = nums[j];
```

Here:

```text
i = 0, 2, 4, 6, ...
j = 0, 1, 2, 3, ...
```

Therefore:

```text
result[0] = nums[0]
result[2] = nums[1]
result[4] = nums[2]
```

---

### Second Loop

We fill the **odd indices** with elements from the second half.

The second half starts at index `n`.

```java
result[i] = nums[n + k];
```

Here:

```text
i = 1, 3, 5, 7, ...
k = 0, 1, 2, 3, ...
```

Therefore:

```text
result[1] = nums[n]
result[3] = nums[n + 1]
result[5] = nums[n + 2]
```

---

## Code

```java
class Solution {

    public int[] shuffle(int[] nums, int n) {

        int[] result = new int[nums.length];

        int j = 0;

        // Fill even positions with elements from first half
        for(int i = 0; i < nums.length; i = i + 2) {

            result[i] = nums[j];

            j++;
        }

        int k = 0;

        // Fill odd positions with elements from second half
        for(int i = 1; i < nums.length; i = i + 2) {

            result[i] = nums[n + k];

            k++;
        }

        return result;
    }
}
```

## Dry Run

Let's take:

```text
nums = [2, 5, 1, 3, 4, 7]
n = 3
```

### First Loop

We take elements from the first half:

```text
[2, 5, 1]
```

and place them at even indices.

| `i` | `j` | `nums[j]` | Result               |
| --: | --: | --------: | -------------------- |
|   0 |   0 |         2 | `[2, _, _, _, _, _]` |
|   2 |   1 |         5 | `[2, _, 5, _, _, _]` |
|   4 |   2 |         1 | `[2, _, 5, _, 1, _]` |

After the first loop:

```text
result = [2, _, 5, _, 1, _]
```

---

### Second Loop

Now take elements from the second half:

```text
[3, 4, 7]
```

and place them at odd indices.

| `i` | `k` |   `nums[n+k]` | Result               |
| --: | --: | ------------: | -------------------- |
|   1 |   0 | `nums[3] = 3` | `[2, 3, 5, _, 1, _]` |
|   3 |   1 | `nums[4] = 4` | `[2, 3, 5, 4, 1, _]` |
|   5 |   2 | `nums[5] = 7` | `[2, 3, 5, 4, 1, 7]` |

Final result:

```text
[2, 3, 5, 4, 1, 7]
```

---

## Important Pattern

The key idea is:

```text
Even indices  → First half
Odd indices   → Second half
```

Visualizing the result:

```text
Index:   0   1   2   3   4   5
         ↓   ↓   ↓   ↓   ↓   ↓
Result:  x1  y1  x2  y2  x3  y3
```

So we use:

```java
i = 0, 2, 4, ...   // even positions
```

for `x` values and:

```java
i = 1, 3, 5, ...   // odd positions
```

for `y` values.

---

## Complexity

### Time Complexity

```text
O(n)
```

We traverse the array twice. Since each loop processes roughly half of the array:

```text
O(n/2) + O(n/2) = O(n)
```

### Space Complexity

```text
O(n)
```

We create a new `result` array of the same size as `nums`.

---

## Key Takeaway

When an array needs to be **rearranged into an alternating pattern**, think about the positions where each group should go.

For this problem:

```text
First half  → even indices
Second half → odd indices
```

This makes the implementation straightforward.
