# LeetCode 1920: Build Array from Permutation

## Problem

You are given a zero-based integer array `nums`. Build a new array `result` of the same length such that:

`result[i] = nums[nums[i]]`

Return the resulting array.

## Java Solution

```java
class Solution {
    public int[] buildArray(int[] nums) {
        int[] result = new int[nums.length];

        for (int i = 0; i < nums.length; i++) {
            result[i] = nums[nums[i]];
        }

        return result;
    }
}
```

## Explanation

### 1. Create a new array

```java
int[] result = new int[nums.length];
```

Creates an array named `result` with the same length as `nums`.

### 2. Traverse the input array

```java
for (int i = 0; i < nums.length; i++) {
    result[i] = nums[nums[i]];
}
```

For each index `i`:

1. Read the value `nums[i]`.
2. Use that value as an index into `nums`.
3. Store `nums[nums[i]]` in `result[i]`.

### 3. Return the result

```java
return result;
```

Returns the newly built array.

## Example Walkthrough

Input:

```text
nums = [0, 2, 1, 5, 3, 4]
```

| `i` | `nums[i]` | `nums[nums[i]]` | `result[i]` |
|---:|---:|---:|---:|
| 0 | 0 | `nums[0] = 0` | 0 |
| 1 | 2 | `nums[2] = 1` | 1 |
| 2 | 1 | `nums[1] = 2` | 2 |
| 3 | 5 | `nums[5] = 4` | 4 |
| 4 | 3 | `nums[3] = 5` | 5 |
| 5 | 4 | `nums[4] = 3` | 3 |

Output:

```text
[0, 1, 2, 4, 5, 3]
```

## Complexity Analysis

- **Time complexity:** `O(n)` because the loop visits each element once.
- **Space complexity:** `O(n)` for the new `result` array.

## Key Idea to Remember

The important expression is:

```java
result[i] = nums[nums[i]];
```

The value at `nums[i]` becomes the index used to access another value in `nums`.
