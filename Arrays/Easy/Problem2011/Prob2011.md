# LeetCode 2011: Final Value of Variable After Performing Operations

## Problem

You are given an array of strings `operations`. Each operation increments or decrements a variable `X`, which starts at `0`.

The possible operations are:

- `++X` and `X++`: increase the value by `1`.
- `--X` and `X--`: decrease the value by `1`.

Return the final value of `X`.

---

## Approach 1: My Solution

### Java Code

```java
class Solution {
    public int finalValueAfterOperations(String[] operations) {
        int value = 0;

        for (int i = 0; i < operations.length; i++) {
            if (operations[i].equals("--X")) {
                value = value - 1;
            } else if (operations[i].equals("X--")) {
                value = value - 1;
            } else if (operations[i].equals("++X")) {
                value = value + 1;
            } else if (operations[i].equals("X++")) {
                value = value + 1;
            }
        }

        return value;
    }
}
```

### Explanation

1. Initialize `value` to `0`.
2. Loop through every operation using the index `i`.
3. If the operation is `--X` or `X--`, decrease `value` by `1`.
4. If the operation is `++X` or `X++`, increase `value` by `1`.
5. Return `value` after processing all operations.

### Complexity

- **Time complexity:** `O(n)`, where `n` is the number of operations.
- **Auxiliary space complexity:** `O(1)`.

---

## Approach 2: Shorter Solution

### Java Code

```java
class Solution {
    public int finalValueAfterOperations(String[] operations) {
        int value = 0;

        for (String op : operations) {
            if (op.charAt(1) == '+') {
                value++;
            } else {
                value--;
            }
        }

        return value;
    }
}
```

### Explanation

#### 1. Use an enhanced `for` loop

```java
for (String op : operations)
```

This visits each operation directly, without needing an index.

#### 2. Check the middle character

```java
if (op.charAt(1) == '+') {
    value++;
} else {
    value--;
}
```

All four operations have either `+` or `-` as their middle character:

| Operation | `op.charAt(1)` | Action |
|---|---|---|
| `++X` | `+` | Increase by 1 |
| `X++` | `+` | Increase by 1 |
| `--X` | `-` | Decrease by 1 |
| `X--` | `-` | Decrease by 1 |

`charAt(1)` returns the character at index `1` (the second character), because Java string indexing starts at `0`.

#### 3. Use increment and decrement operators

- `value++` is shorthand for increasing `value` by `1`.
- `value--` is shorthand for decreasing `value` by `1`.

#### 4. Return the final value

```java
return value;
```

## Example Walkthrough

Input:

```text
operations = ["--X", "X++", "X++"]
```

| Operation | Action | Value |
|---|---|---:|
| Initial value | — | 0 |
| `--X` | Decrease by 1 | -1 |
| `X++` | Increase by 1 | 0 |
| `X++` | Increase by 1 | 1 |

Output:

```text
1
```

## Comparison

| Feature | Your solution | Shorter solution |
|---|---|---|
| Loop | Index-based `for` loop | Enhanced `for` loop |
| Conditions | Checks all four strings | Checks the middle character |
| Code length | Longer | Shorter |
| Time complexity | `O(n)` | `O(n)` |
| Auxiliary space | `O(1)` | `O(1)` |

Both solutions produce the same result for the four valid operations. The shorter version works because the middle character alone tells us whether to increment or decrement.

## Key Idea to Remember

When several strings follow a fixed pattern, look for a character that distinguishes the cases. Here, `op.charAt(1)` is enough to determine the operation.
