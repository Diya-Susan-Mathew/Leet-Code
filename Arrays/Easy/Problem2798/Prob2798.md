# Number of Employees Who Met the Target

## Problem Statement

You are given an integer array `hours`, where `hours[i]` represents the total number of hours worked by the `i-th` employee during a week. You are also given an integer `target`, which represents the minimum number of working hours required for an employee to meet the target.

Your task is to count the number of employees who have worked **at least `target` hours**.

An employee is considered to have met the target if their working hours are greater than or equal to the given target.

Return the total number of employees who met the target.

## Example 1

**Input:**
```text
hours = [0, 1, 2, 3, 4]
target = 2
```

**Explanation:**

- Employee 1 worked 0 hours → Did not meet the target.
- Employee 2 worked 1 hour → Did not meet the target.
- Employee 3 worked 2 hours → Met the target.
- Employee 4 worked 3 hours → Met the target.
- Employee 5 worked 4 hours → Met the target.

Since 3 employees worked at least 2 hours, the answer is **3**.

**Output:**
```text
3
```

## Example 2

**Input:**
```text
hours = [5, 1, 4, 2, 2]
target = 6
```

**Explanation:**

No employee worked for 6 hours or more. Therefore, no employee met the target.

**Output:**
```text
0
```

## Java Solution

```java
class Solution {
    public int numberOfEmployeesWhoMetTarget(int[] hours, int target) {
        int count = 0;
        for(int i = 0; i < hours.length; i++) {
            if(hours[i] >= target) {
                count++;
            }
        }
        return count;
    }
}
```

## Approach: Linear Traversal

1. Initialize `count` to 0.
2. Traverse the `hours` array.
3. Check whether each employee's working hours are greater than or equal to `target`.
4. If the condition is satisfied, increment `count`.
5. Return the final count.

## Complexity Analysis

- **Time Complexity:** O(n) – Each element is visited exactly once.
- **Space Complexity:** O(1) – Only a constant amount of extra space is used.
