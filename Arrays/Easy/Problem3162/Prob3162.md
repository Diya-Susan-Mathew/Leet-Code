# Number of Pairs

## Problem

Given two integer arrays, `nums1` and `nums2`, and an integer `k`, count
the number of pairs `(i, j)` such that:

`nums1[i]` is divisible by `nums2[j] * k`.

In other words, for every pair of elements, check whether:

``` text
nums1[i] % (nums2[j] * k) == 0
```

If the condition is true, increment the pair count.

## Java Solution

``` java
class Solution {
    public int numberOfPairs(int[] nums1, int[] nums2, int k) {
        int n = nums1.length, m = nums2.length;
        int pairs = 0;

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                if (nums1[i] % (nums2[j] * k) == 0) {
                    pairs++;
                }
            }
        }

        return pairs;
    }
}
```

## Explanation

1.  Find the lengths of both arrays and initialize `pairs` to `0`.
2.  The outer loop iterates through every element of `nums1`.
3.  The inner loop iterates through every element of `nums2`.
4.  For each combination, calculate `nums2[j] * k`.
5.  Check whether `nums1[i]` is divisible by that value using the modulo
    (`%`) operator.
6.  If the remainder is `0`, the pair satisfies the condition, so
    increment `pairs`.
7.  Return the total number of valid pairs.

## Example

``` text
nums1 = [1, 3, 4]
nums2 = [1, 3, 4]
k = 1
```

Check each pair:

    `nums1[i]`   `nums2[j]`   `nums2[j] * k` Divisible?
  ------------ ------------ ---------------- ------------
             1            1                1 Yes
             1            3                3 No
             1            4                4 No
             3            1                1 Yes
             3            3                3 Yes
             3            4                4 No
             4            1                1 Yes
             4            3                3 No
             4            4                4 Yes

The valid pairs are `(1, 1)`, `(3, 1)`, `(3, 3)`, `(4, 1)`, and
`(4, 4)`.

**Output:**

``` text
5
```

## Complexity Analysis
a
Let: - `n` be the length of `nums1`. - `m` be the length of `nums2`.

**Time Complexity: `O(n * m)`**

The nested loops examine every possible pair of elements, so there are
`n * m` checks.

**Space Complexity: `O(1)`**

The algorithm uses only a fixed number of extra variables, regardless of
the input size.

## Important Note

This implementation assumes that `nums2[j] * k` is non-zero and that the
multiplication does not overflow an `int`. If the constraints allow
large values, use `long` for the multiplication and modulo calculation.
