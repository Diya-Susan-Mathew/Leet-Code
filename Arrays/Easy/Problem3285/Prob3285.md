# Stable Mountains

## 1. Understanding the Question

You are given: - An integer array `height`, where `height[i]` represents
the height of a mountain at index `i`. - An integer `threshold`.

A mountain is **stable** if the mountain immediately before it has a
height strictly greater than `threshold`.

For a mountain at index `i`, the condition is:

``` java
height[i - 1] > threshold
```

The first mountain (index `0`) cannot be stable because it has no
previous mountain.

**Important:** Return the index of the stable mountain, not the index of
the previous mountain.

## 2. Example

**Input:**

``` text
height = [1, 2, 3, 4, 5]
threshold = 2
```

Check each mountain from index `1` onwards:

  -------------------------------------------------------------------------
         Current index  Previous mountain's Is it greater   Is current
                                     height than `2`?       mountain
                                                            stable?
  -------------------- -------------------- --------------- ---------------
                     1                    1 No              No

                     2                    2 No (`2` is not  No
                                            greater than    
                                            `2`)            

                     3                    3 Yes             Yes

                     4                    4 Yes             Yes
  -------------------------------------------------------------------------

Therefore, the stable mountains are at indices `3` and `4`.

**Output:**

``` text
[3, 4]
```

Notice that the comparison is strictly greater than (`>`), not greater
than or equal to (`>=`).

## 3. My Java Code

``` java
class Solution {
    public List<Integer> stableMountains(int[] height, int threshold) {
        List<Integer> list = new ArrayList<>();
        for(int i=0;i<height.length;i++){
            if(i == height.length - 1){
                break;
            }
            else if(height[i] > threshold &&(height[i+1]<threshold || height[i+1] >= threshold)){
                list.add(i+1);
            }
        }
        return list;
    }
}
```

## 4. Explanation of Code

### Step 1: Create a result list

``` java
List<Integer> list = new ArrayList<>();
```

This list stores the indices of all stable mountains.

### Step 2: Traverse the array

``` java
for (int i = 0; i < height.length; i++)
```

We traverse the array to check whether each mountain can make the next
mountain stable.

### Step 3: Stop at the last element

``` java
if (i == height.length - 1) {
    break;
}
```

The last element has no mountain after it. It cannot be used as the
previous mountain when checking a next mountain.

### Step 4: Check the previous mountain's height

``` java
height[i] > threshold
```

If the current mountain's height is greater than the threshold, the
mountain at the next index (`i + 1`) is stable.

Your complete condition also contains:

``` java
height[i + 1] < threshold || height[i + 1] >= threshold
```

This part is always true: every number is either less than the threshold
or greater than or equal to it. Therefore, it is unnecessary.

### Step 5: Add the stable mountain's index

``` java
list.add(i + 1);
```

We add `i + 1` because the mountain that is stable is the **next
mountain**, not the current one.

For example, if `i = 2`, then `height[2]` is the previous mountain. If
it is greater than the threshold, the stable mountain is at index `3`.

### Step 6: Return the result

``` java
return list;
```

This returns all stable mountain indices.

## 5. Simplified Version

``` java
class Solution {
    public List<Integer> stableMountains(int[] height, int threshold) {
        List<Integer> list = new ArrayList<>();

        for (int i = 0; i < height.length - 1; i++) {
            if (height[i] > threshold) {
                list.add(i + 1);
            }
        }

        return list;
    }
}
```

This simplified code produces the same output as your original code.

## 6. Complexity Analysis

Let `n` be the length of the `height` array.

-   **Time Complexity: `O(n)`** --- We traverse the array once.
-   **Auxiliary Space Complexity: `O(1)`** --- Excluding the result
    list, only a constant amount of extra working space is used.
-   **Result List Space: `O(n)`** --- In the worst case, the list can
    contain up to `n - 1` indices.

## 7. Key Points to Remember

1.  A mountain is stable based on the height of the mountain immediately
    before it.
2.  The condition is `height[i - 1] > threshold`.
3.  The comparison is strictly greater than (`>`), not greater than or
    equal to (`>=`).
4.  The first mountain cannot be stable.
5.  Return the index of the stable mountain, not the index of the
    mountain used to check its stability.
