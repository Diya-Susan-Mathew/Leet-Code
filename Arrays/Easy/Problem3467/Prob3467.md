
# Transform Array

## Problem
Transform the given array such that all even numbers are replaced with `0` and all odd numbers are replaced with `1`. All zeros should appear before all ones.

## Approach: Counting

1. Initialize two counters: `evenCount` and `oddCount`.
2. Traverse the array and count the number of even and odd elements.
3. Replace the first `evenCount` elements with `0`.
4. Replace the remaining elements with `1`.
5. Return the transformed array.

## Java Solution

```java
class Solution {
    public int[] transformArray(int[] nums) {
        int evenCount = 0, oddCount = 0;

        for (int i = 0; i < nums.length; i++) {
            if (nums[i] % 2 == 0) {
                evenCount++;
            } else {
                oddCount++;
            }
        }

        for (int i = 0; i < evenCount; i++) {
            nums[i] = 0;
        }

        for (int i = evenCount; i < nums.length; i++) {
            nums[i] = 1;
        }

        return nums;
    }
}
```

## Complexity Analysis

- **Time Complexity:** O(n) – Two traversals of the array.
- **Space Complexity:** O(1) – Modifications are performed in-place without using extra space.

## Key Concept
Array Traversal + Counting + In-place Modification
