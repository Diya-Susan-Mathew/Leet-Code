# LeetCode Solution: Minimum Operations to Make Array Sum Divisible by K

## Approach

1. Initialize a variable `sum` to `0`.
2. Iterate through the array and calculate the sum of all elements.
3. Return `sum % k`, which gives the remainder when the total sum is divided by `k`.

## Java Code

```java
class Solution {
    public int minOperations(int[] nums, int k) {
        int sum = 0;

        for (int i = 0; i < nums.length; i++) {
            sum += nums[i];
        }

        return sum % k;
    }
}
```

## Complexity Analysis

- **Time Complexity:** `O(n)` — We traverse the array once.
- **Space Complexity:** `O(1)` — We use only one additional variable, `sum`.

## Example

**Input:** `nums = [3, 9, 7]`, `k = 5`

- Sum of elements: `3 + 9 + 7 = 19`
- Remainder: `19 % 5 = 4`

**Output:** `4`

## Key Idea

The minimum number of operations equals the remainder of the total sum divided by `k`, because each operation decreases an element by `1`.
