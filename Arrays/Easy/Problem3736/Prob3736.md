
# Minimum Moves

## Problem
Find the minimum number of moves required to make all elements of the array equal. In each move, you can increment `n - 1` elements by 1.

## Approach: Maximum Element and Array Sum

1. Find the maximum element in the array.
2. Calculate the sum of all array elements.
3. Calculate the expected sum if every element were equal to the maximum element.
4. Subtract the current sum from the expected sum to obtain the minimum number of moves.

## Java Solution

```java
class Solution {
    public int minMoves(int[] nums) {
        int arraySum = 0;
        int max = Integer.MIN_VALUE;

        for(int i = 0; i < nums.length; i++) {
            arraySum += nums[i];

            if(max < nums[i]) {
                max = nums[i];
            }
        }

        int expectedSum = max * nums.length;
        return expectedSum - arraySum;
    }
}
```

## Complexity Analysis

- **Time Complexity:** O(n) – We traverse the array once.
- **Space Complexity:** O(1) – Only a constant amount of extra space is used.

## Key Formula

Minimum Moves = (Maximum Element × Array Length) − Array Sum

## Example

Input: `nums = [1, 2, 3]`

- Maximum element = 3
- Array sum = 1 + 2 + 3 = 6
- Expected sum = 3 × 3 = 9
- Minimum moves = 9 − 6 = 3

Output: `3`
