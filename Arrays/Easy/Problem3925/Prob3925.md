# Concatenate Array With Its Reverse

## Problem Statement

Given an integer array `nums`, create a new array by concatenating the
original array with a reversed copy of itself.

In other words: - The first half of the result must contain the elements
of `nums` in their original order. - The second half must contain the
elements of `nums` in reverse order.

Return the resulting array.

## Example

**Input:**

``` text
nums = [1, 2, 3]
```

**Output:**

``` text
[1, 2, 3, 3, 2, 1]
```

**Explanation:**

The original array is `[1, 2, 3]`.

Its reverse is `[3, 2, 1]`.

Concatenating the original array and its reverse gives:

`[1, 2, 3] + [3, 2, 1] = [1, 2, 3, 3, 2, 1]`

The resulting array has twice as many elements as the original array.

## Java Solution

``` java
class Solution {
    public int[] concatWithReverse(int[] nums) {
        int[] result = new int[2 * nums.length];

        // Copy the original array
        for (int i = 0; i < nums.length; i++) {
            result[i] = nums[i];
        }

        // Append the elements in reverse order
        int j = nums.length - 1;
        for (int i = nums.length; i < result.length; i++) {
            result[i] = nums[j];
            j--;
        }

        return result;
    }
}
```

## Code Explanation

### 1. Create the result array

``` java
int[] result = new int[2 * nums.length];
```

The resulting array must contain the original array and its reverse.
Therefore, its length is twice the length of `nums`.

For example, if `nums.length` is 3, the result array has a length of 6.

### 2. Copy the original array

``` java
for (int i = 0; i < nums.length; i++) {
    result[i] = nums[i];
}
```

This loop copies all elements of `nums` into the first half of `result`.

For `nums = [1, 2, 3]`, the result array becomes:

`[1, 2, 3, 0, 0, 0]`

(The remaining positions initially contain Java's default integer value,
`0`.)

### 3. Initialize the reverse pointer

``` java
int j = nums.length - 1;
```

The variable `j` points to the last element of the original array
because array indexing starts at 0.

For an array of length 3, `j = 2`, which points to the element `3`.

### 4. Copy elements in reverse order

``` java
for (int i = nums.length; i < result.length; i++) {
    result[i] = nums[j];
    j--;
}
```

-   `i` starts at `nums.length`, the first index of the second half of
    `result`.
-   `j` starts at the last index of `nums`.
-   Each iteration copies `nums[j]` into `result[i]`.
-   `j--` moves the pointer backwards through the original array.

For example:

  Iteration     `i`   `j`   Value copied
  ----------- ----- ----- --------------
  1               3     2              3
  2               4     1              2
  3               5     0              1

The result becomes `[1, 2, 3, 3, 2, 1]`.

### 5. Return the result

``` java
return result;
```

Returns the newly created array containing the original array followed
by its reverse.

## Complexity Analysis

Let `n` be the number of elements in the input array.

-   **Time Complexity: O(n)** --- The first loop runs `n` times, and the
    second loop also runs `n` times. Therefore, the total work is
    proportional to `2n`, which simplifies to `O(n)`.
-   **Space Complexity: O(n)** --- A new array of size `2n` is created
    to store the result. Therefore, the additional space is `O(n)`.
