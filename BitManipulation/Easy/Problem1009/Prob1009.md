# Bitwise Complement

## Problem

Given a positive integer `n`, return its **bitwise complement**.

The complement means:

```text
0 → 1
1 → 0
```

### Important

We only complement the bits that are actually present in the binary representation of `n`.

For example:

```text
n = 5
5 = 101
```

Complement:

```text
101
↓
010
```

So:

```text
Answer = 2
```

---

# Approach

The main idea is to create a **mask containing only `1`s** with the same number of bits as `n`.

Then:

```text
mask XOR n
```

will flip every bit of `n`.

---

# Why Do We Need a Mask?

Suppose:

```text
n = 5
```

Binary:

```text
101
```

We want:

```text
101
↓
010
```

If we simply use:

```java
~n
```

we would flip **all 32 bits** of the Java integer.

For example:

```text
00000000...00000101
```

would become:

```text
11111111...11111010
```

That is not what the problem wants.

We only want to flip:

```text
101
```

Therefore, we create:

```text
111
```

and perform:

```text
111
^ 101
-----
010
```

So:

```text
mask ^ n
```

gives the required complement.

---

# Creating the Mask

We start with:

```java
int mask = 1;
```

Then:

```java
mask = (mask << 1) + 1;
```

This creates a number consisting of all `1`s.

### Example

Start:

```text
mask = 1
```

Binary:

```text
1
```

Shift left:

```text
1 << 1 = 10
```

Add `1`:

```text
10 + 1 = 11
```

Again:

```text
11 << 1 = 110
110 + 1 = 111
```

So:

```text
1 → 11 → 111 → 1111 → ...
```

---

# Code

```java
class Solution {

    public int bitwiseComplement(int n) {

        if (n < 0) {
            return 0;
        }

        int mask = 1;

        while (mask < n) {
            mask = (mask << 1) + 1;
        }

        return mask ^ n;
    }
}
```

# Understanding `(mask << 1) + 1`

This is an important bit manipulation pattern.

Suppose:

```text
mask = 111
```

Left shift:

```text
111 << 1
```

gives:

```text
1110
```

Then add `1`:

```text
1110 + 1 = 1111
```

So:

```text
111 → 1111
```

It adds another `1` to the right.

Therefore:

```text
(mask << 1) + 1
```

is a way to create:

```text
1
11
111
1111
11111
...
```

---

# Why `mask < n`?

We need the mask to have the **same number of bits** as `n`.

For:

```text
n = 5 = 101
```

we need:

```text
mask = 111
```

When:

```text
mask = 1
```

it is too small.

When:

```text
mask = 3 = 11
```

it is still too small.

When:

```text
mask = 7 = 111
```

it is large enough.

So the loop stops when:

```text
mask >= n
```

---

# Special Case: n = 0

There is an important edge case.

If:

```text
n = 0
```

the binary representation is:

```text
0
```

Its complement is:

```text
1
```

Your code handles this correctly:

```text
mask = 1
```

The condition:

```text
1 < 0
```

is false.

Then:

```text
1 ^ 0 = 1
```

So the answer is:

```text
1
```

---

# Why Not Just Use `~n`?

You might think:

```java
return ~n;
```

But Java `int` uses **32 bits**.

For:

```text
n = 5
```

we have:

```text
00000000 00000000 00000000 00000101
```

`~n` gives:

```text
11111111 11111111 11111111 11111010
```

which represents a negative number.

The problem wants the complement of:

```text
101
```

not all 32 bits.

That's why we use a mask.

---

# Alternative Approach: XOR With a Mask

The core formula is:

```text
Complement = mask ^ n
```

where:

```text
mask = 111...111
```

with the same number of bits as `n`.

For example:

```text
n    = 1010
mask = 1111

1010 ^ 1111 = 0101
```

---

# Alternative Java Solution

Java doesn't have a direct `bitwiseComplement()` method, but we can create the mask using `Integer.highestOneBit()`.

However, your current approach is simpler and easier to understand for learning bit manipulation.

---

# Complexity

Let `b` be the number of bits in `n`.

The loop runs approximately once for each bit.

### Time Complexity

```text
O(log n)
```

### Space Complexity

```text
O(1)
```

Only a few integer variables are used.


```text
n    = 1010

mask ^ n
   ↓
0101
```

---

# Key Takeaways

### 1. `~n` flips all 32 bits

So it is not directly suitable here.

### 2. Create a mask of all `1`s

```text
1 → 11 → 111 → 1111 → ...
```

Using:

```java
mask = (mask << 1) + 1;
```

### 3. XOR flips the required bits

```text
1 ^ 0 = 1
1 ^ 1 = 0
```

Therefore:

```text
mask ^ n
```

produces the complement.

---

# Final Pattern

```text
       n
       ↓
Find number of bits
       ↓
Create mask: 111...111
       ↓
      XOR
       ↓
Bitwise Complement
```

For example:

```text
n = 5

  111  ← mask
^ 101  ← n
-----
  010

Answer = 2
```
