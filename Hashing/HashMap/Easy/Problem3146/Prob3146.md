# LeetCode: Find Permutation Difference

## Problem

Given two strings `s` and `t` that are permutations of each other, calculate the **permutation difference** between them.

For each character, find its index in both strings, take the absolute difference between those indices, and add all the differences.

## My Solution

```java
class Solution {
    public int findPermutationDifference(String s, String t) {
        Map<Character,Integer> map1 = new HashMap<>();
        Map<Character,Integer> map2 = new HashMap<>();

        for (int i = 0; i < s.length(); i++) {
            map1.put(s.charAt(i), i);
        }

        for (int i = 0; i < t.length(); i++) {
            map2.put(t.charAt(i), i);
        }

        int diff = 0, sum = 0;

        for (Map.Entry<Character, Integer> entry : map1.entrySet()) {
            char key = entry.getKey();
            int value = entry.getValue();
            diff = Math.abs(value - map2.get(key));
            sum += diff;
        }

        return sum;
    }
}
```

## Optimized Solution

```java
class Solution {
    public int findPermutationDifference(String s, String t) {
        Map<Character, Integer> map = new HashMap<>();

        // Store each character and its index from string s
        for (int i = 0; i < s.length(); i++) {
            map.put(s.charAt(i), i);
        }

        int sum = 0;

        // Calculate the absolute difference with indices in t
        for (int i = 0; i < t.length(); i++) {
            char ch = t.charAt(i);
            sum += Math.abs(map.get(ch) - i);
        }

        return sum;
    }
}
```

## How the Optimized Solution Works

1. Store each character's index in `s` in a `HashMap`.
2. Traverse `t` from left to right.
3. For each character in `t`, retrieve its index in `s` using `map.get(ch)`.
4. The character's index in `t` is the current loop index `i`.
5. Add `Math.abs(map.get(ch) - i)` to `sum`.
6. Return `sum`.

## Example

```text
s = "abc"
t = "bac"
```

| Character | Index in `s` | Index in `t` | Absolute difference |
|---|---:|---:|---:|
| a | 0 | 1 | 1 |
| b | 1 | 0 | 1 |
| c | 2 | 2 | 0 |

**Permutation difference = 1 + 1 + 0 = 2**

## Comparison

| Aspect | My solution | Optimized solution |
|---|---|---|
| HashMaps used | 2 | 1 |
| Passes to build maps | 2 | 1 |
| Passes to calculate the sum | 1 | 1 |
| Time complexity | `O(n)` | `O(n)` |
| Auxiliary space | `O(k)` | `O(k)` |

Here, `n` is the string length and `k` is the number of distinct characters. Since the strings are permutations, each character appears once, so `k = n`.

## Why the Optimized Solution Is Better

Your solution is correct and has **O(n)** time complexity. It stores the indices of both strings in two maps, then compares the indices for every character.

The optimized solution stores only the indices from `s`. While traversing `t`, the current index `i` already gives each character's position in `t`, so a second map is unnecessary.

This makes the code shorter and reduces extra map storage, while keeping the same **O(n)** time complexity.

## Complexity of the Optimized Solution

- **Time:** `O(n)` — one pass through `s` and one pass through `t`.
- **Auxiliary space:** `O(n)` — the map stores each character's index.
