# LeetCode: Count the Number of Consistent Strings

## Problem Idea

A string is **consistent** if every character in the string exists in `allowed`. Given a string `allowed` and an array of strings `words`, return the number of consistent strings.

This file compares two approaches:
1. My approach using a `HashSet<Character>`.
2. An optimized approach using a `boolean[26]` array for lowercase English letters.

## Example 1

**Input**
```text
allowed = "ab"
words = ["ad", "bd", "aaab", "baa", "badab"]
```

**Walkthrough**

- `"ad"` → Not consistent because `d` is not in `"ab"`.
- `"bd"` → Not consistent because `d` is not in `"ab"`.
- `"aaab"` → Consistent because every character is either `a` or `b`.
- `"baa"` → Consistent because every character is either `a` or `b`.
- `"badab"` → Not consistent because it contains `d`.

**Output**
```text
2
```

The consistent strings are `"aaab"` and `"baa"`.

## Example 2

**Input**
```text
allowed = "abc"
words = ["a", "b", "c", "ab", "ac", "bc", "abc"]
```

**Walkthrough**

Every word contains only characters from `a`, `b`, and `c`, so all seven words are consistent.

**Output**
```text
7
```

## Example 3

**Input**
```text
allowed = "x"
words = ["x", "xx", "xy", "y", "xxx"]
```

**Walkthrough**

- `"x"` → Consistent
- `"xx"` → Consistent
- `"xy"` → Not consistent because `y` is not allowed
- `"y"` → Not consistent
- `"xxx"` → Consistent

**Output**
```text
3
```

## Approach 1: My Solution — HashSet

### Java Code

```java
import java.util.HashSet;

class Solution {
    public int countConsistentStrings(String allowed, String[] words) {
        HashSet<Character> set = new HashSet<>();

        for (int i = 0; i < allowed.length(); i++) {
            set.add(allowed.charAt(i));
        }

        int counter = 0;

        for (int i = 0; i < words.length; i++) {
            String word = words[i];
            counter++;

            for (int j = 0; j < word.length(); j++) {
                if (!set.contains(word.charAt(j))) {
                    counter--;
                    break;
                }
            }
        }

        return counter;
    }
}
```

### How It Works

1. Add every character in `allowed` to a `HashSet`.
2. Assume each word is consistent by incrementing `counter`.
3. Check each character in the word.
4. If a character is not in the set, decrement `counter` and stop checking that word.
5. Return the number of consistent words.

### Example Dry Run

For `allowed = "ab"` and `words = ["ad", "bd", "aaab", "baa", "badab"]`:

| Word | Check | Result | Counter |
|---|---|---|---:|
| `"ad"` | `d` is not in the set | Not consistent | 0 |
| `"bd"` | `d` is not in the set | Not consistent | 0 |
| `"aaab"` | All characters are allowed | Consistent | 1 |
| `"baa"` | All characters are allowed | Consistent | 2 |
| `"badab"` | `d` is not in the set | Not consistent | 2 |

Final answer: `2`

## Approach 2: Boolean Array

### Java Code

```java
class Solution {
    public int countConsistentStrings(String allowed, String[] words) {
        boolean[] allowedChars = new boolean[26];

        for (int i = 0; i < allowed.length(); i++) {
            allowedChars[allowed.charAt(i) - 'a'] = true;
        }

        int counter = 0;

        for (String word : words) {
            counter++;

            for (int j = 0; j < word.length(); j++) {
                if (!allowedChars[word.charAt(j) - 'a']) {
                    counter--;
                    break;
                }
            }
        }

        return counter;
    }
}
```

### How It Works

1. Create a boolean array of length `26`, with one slot for each lowercase English letter.
2. For each character `c` in `allowed`, mark `allowedChars[c - 'a']` as `true`.
3. For each word, initially count it as consistent.
4. If a character's array entry is `false`, decrement the counter and stop checking that word.
5. Return the counter.

### Why `character - 'a'` Works

Each lowercase English letter maps to an index from `0` to `25`:

| Character | Index |
|---|---:|
| `'a'` | `'a' - 'a' = 0` |
| `'b'` | `'b' - 'a' = 1` |
| `'c'` | `'c' - 'a' = 2` |
| ... | ... |
| `'z'` | `'z' - 'a' = 25` |

For example, if `allowed = "ab"`, then `allowedChars[0]` and `allowedChars[1]` become `true`. All other entries remain `false`.

## Complexity Analysis

Let:
- `A` be the length of `allowed`.
- `T` be the total number of characters across all strings in `words`.

| Approach | Time Complexity | Auxiliary Space |
|---|---|---|
| `HashSet<Character>` | `O(A + T)` on average | `O(1)` for lowercase English letters, at most 26 distinct characters |
| `boolean[26]` | `O(A + T)` | `O(1)` because the array always has 26 entries |

Both approaches are **O(A + T)** in the worst case. The boolean array avoids hashing overhead, but your `HashSet` solution is also efficient and correct for lowercase English letters.

## Key Difference

- **HashSet:** Stores allowed characters as set elements and checks membership with `set.contains(character)`.
- **Boolean array:** Uses the character's alphabet index (`character - 'a'`) to check membership directly.

The boolean array is a useful optimization when the input is guaranteed to contain only lowercase English letters. Your `HashSet` approach is a good solution too, and it expresses the membership check clearly.
