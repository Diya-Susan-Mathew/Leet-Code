# Check If Pangram

## Approach

- Use a `HashSet` to store all unique characters in the sentence.
- A pangram contains all **26 lowercase English letters**.
- If the set contains 26 unique characters, return `true`; otherwise, return `false`.

## Code

```java
class Solution {
    public boolean checkIfPangram(String sentence) {
        HashSet<Character> set = new HashSet<>();

        for (char c : sentence.toCharArray()) {
            set.add(c);
        }

        int count = set.size();

        if (count == 26) {
            return true;
        }

        return false;
    }
}
```

## Complexity

- **Time:** `O(n)`
- **Space:** `O(1)` — at most 26 characters
