# Subtract the Product and Sum of Digits

## Problem

Given an integer `n`, find the **product of its digits** and the **sum of its digits**, then return:

```text
Product of digits - Sum of digits
```

### Example

**Input:**

```text
n = 234
```

**Output:**

```text
15
```

### Explanation

Digits are `2, 3, 4`.

**Sum:**

```text
2 + 3 + 4 = 9
```

**Product:**

```text
2 × 3 × 4 = 24
```

Therefore:

```text
24 - 9 = 15
```

---

## Approach

We need to extract each digit from the number.

We can use:

```java
n % 10
```

to get the **last digit**.

Then:

```java
n / 10
```

removes the **last digit**.

We repeat this until `n` becomes `0`.

### Steps

For every digit:

1. Extract the last digit using `n % 10`.
2. Add it to `sum`.
3. Multiply it with `pdt`.
4. Remove the last digit using `n / 10`.
5. Continue until `n == 0`.

---

## Code

```java
class Solution {

    public int subtractProductAndSum(int n) {

        int num = 0;
        int sum = 0;
        int pdt = 1;

        while(n > 0) {

            num = n % 10;

            sum += num;

            pdt *= num;

            n = n / 10;
        }

        return pdt - sum;
    }
}
```

## Dry Run

Let's take:

```text
n = 234
```

### Iteration 1

```text
num = 234 % 10
    = 4
```

```text
sum = 0 + 4 = 4
pdt = 1 × 4 = 4
n = 234 / 10 = 23
```

### Iteration 2

```text
num = 23 % 10
    = 3
```

```text
sum = 4 + 3 = 7
pdt = 4 × 3 = 12
n = 23 / 10 = 2
```

### Iteration 3

```text
num = 2 % 10
    = 2
```

```text
sum = 7 + 2 = 9
pdt = 12 × 2 = 24
n = 2 / 10 = 0
```

Loop stops.

Finally:

```text
pdt - sum
= 24 - 9
= 15
```

## Important Concepts

### 1. Extracting the last digit

```java
num = n % 10;
```

Example:

```text
234 % 10 = 4
23 % 10  = 3
2 % 10   = 2
```

So we get the digits from **right to left**.

---

### 2. Removing the last digit

```java
n = n / 10;
```

Example:

```text
234 / 10 = 23
23 / 10  = 2
2 / 10   = 0
```

Since this is integer division, the decimal part is removed.

---

## Pattern to Remember

Whenever a problem asks you to **work with individual digits of an integer**, think:

```java
while(n > 0) {

    int digit = n % 10;

    // process digit

    n = n / 10;
}
```

This is a very important **basic number manipulation pattern**.

---

## Complexity

### Time Complexity

```text
O(log n)
```

A number with `d` digits requires `d` iterations.

Since the number of digits is approximately `log₁₀(n)`, the complexity is `O(log n)`.

### Space Complexity

```text
O(1)
```

Only a few variables are used.

---

## Key Takeaway

Remember these two operations:

```text
n % 10  → get the last digit

n / 10  → remove the last digit
```

Together, they allow you to process **every digit of a number**.
