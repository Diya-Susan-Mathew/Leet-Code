# Count Odd Numbers in an Interval

## Problem

Given two non-negative integers `low` and `high`, return the number of **odd numbers** between `low` and `high`, including both endpoints.

### Example

**Input:**

```text
low = 3
high = 7
```

**Output:**

```text
3
```

The odd numbers are:

```text
3, 5, 7
```

---

## Approach

Instead of checking every number from `low` to `high`, we can directly calculate how many odd numbers exist.

The key formula is:

```java
(high + 1) / 2 - low / 2
```

### Why does `(high + 1) / 2` work?

It gives the number of odd numbers from `1` to `high`.

For example:

```text
high = 7

(7 + 1) / 2
= 8 / 2
= 4
```

Odd numbers from `1` to `7`:

```text
1, 3, 5, 7
```

There are `4`.

---

### Why do we use `low / 2`?

```text
low / 2
```

gives the number of odd numbers **before `low`**.

For:

```text
low = 3
```

```text
3 / 2 = 1
```

There is one odd number before `3`:

```text
1
```

So:

```text
Odd numbers from 1 to high
-
Odd numbers before low
```

gives the number of odd numbers in `[low, high]`.

---

## Code

```java
class Solution {
    public int countOdds(int low, int high) {

        int countUptoHigh = (high + 1) / 2;

        int countBeforeLow = low / 2;

        int oddNos = countUptoHigh - countBeforeLow;

        return oddNos;

        // return (high + 1) / 2 - low / 2;
    }
}
```

---

## Dry Run

Let's take:

```text
low = 3
high = 7
```

### Step 1: Count odd numbers up to `high`

```text
countUptoHigh = (7 + 1) / 2
              = 8 / 2
              = 4
```

Odd numbers from `1` to `7`:

```text
1, 3, 5, 7
```

Count = `4`

---

### Step 2: Count odd numbers before `low`

```text
countBeforeLow = 3 / 2
               = 1
```

The odd number before `3` is:

```text
1
```

Count = `1`

---

### Step 3: Subtract

```text
oddNos = 4 - 1
       = 3
```

Therefore:

```text
3, 5, 7
```

There are `3` odd numbers.

## Another Example

```text
low = 8
high = 10
```

Numbers:

```text
8, 9, 10
```

Only `9` is odd.

Using the formula:

```text
(high + 1) / 2 - low / 2

(10 + 1) / 2 - 8 / 2

11 / 2 - 4

5 - 4

= 1
```

Answer = `1`.

## Important Integer Division Concept

Java performs **integer division** when both operands are integers.

For example:

```java
7 / 2 = 3
8 / 2 = 4
```

The decimal part is discarded.

This is important for understanding why the formula works.

## Key Pattern

This problem teaches an important technique:

> **Instead of iterating through a range, calculate the answer using a mathematical formula.**

Remember:

```text
Number of odds from 1 to n
= (n + 1) / 2
```

And therefore:

```text
Odds in [low, high]
= (high + 1) / 2 - low / 2
```
