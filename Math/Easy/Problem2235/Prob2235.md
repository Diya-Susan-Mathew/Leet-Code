# LeetCode 2235 – Add Two Integers

## Problem

Given two integers `num1` and `num2`, return their **sum**.

---

## Approach

This is a very simple arithmetic problem.

We are given two integers:

```text
num1
num2
```

To find their sum, use the `+` operator:

```java
num1 + num2
```

Then return the result.

---

## Code

```java
class Solution {

    public int sum(int num1, int num2) {

        return num1 + num2;

    }

}
```
