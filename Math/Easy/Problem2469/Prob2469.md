# LeetCode 2469 – Convert the Temperature

## Problem

You are given a temperature in **Celsius**.

Convert it into:

1. **Kelvin**
2. **Fahrenheit**

Return both values in an array.

---

## Formulas

### Celsius → Kelvin

```text
Kelvin = Celsius + 273.15
```

### Celsius → Fahrenheit

```text
Fahrenheit = Celsius × 1.80 + 32.00
```

---

## Approach

We need to calculate two values from the given `celsius`.

### Step 1: Create an array

Since we need to return **two values**, create a `double` array of size `2`.

```java
double[] result = new double[2];
```

The indexes will represent:

```text
result[0] → Kelvin
result[1] → Fahrenheit
```

### Step 2: Calculate Kelvin

```java
result[0] = celsius + 273.15;
```

### Step 3: Calculate Fahrenheit

```java
result[1] = celsius * 1.80 + 32.00;
```

### Step 4: Return the array

```java
return result;
```

---

## Code

```java
class Solution {

    public double[] convertTemperature(double celsius) {

        double[] result = new double[2];

        result[0] = celsius + 273.15;

        result[1] = celsius * 1.80 + 32.00;

        return result;

    }
}
```

---

## Dry Run

### Input

```text
celsius = 36.50
```

### Step 1: Calculate Kelvin

```text
Kelvin = 36.50 + 273.15
       = 309.65
```

So:

```text
result[0] = 309.65
```

### Step 2: Calculate Fahrenheit

```text
Fahrenheit = 36.50 × 1.80 + 32.00
           = 65.70 + 32.00
           = 97.70
```

So:

```text
result[1] = 97.70
```

### Final Array

```text
[309.65, 97.70]
```

---

## Understanding the Array

The return type is:

```java
double[]
```

because we need to return **two decimal values**.

```text
             result
          ┌─────────────┐
index 0 → │   Kelvin    │
          ├─────────────┤
index 1 → │ Fahrenheit  │
          └─────────────┘
```

For example:

```java
double[] result = new double[2];

result[0] = 309.65;
result[1] = 97.70;
```

The array becomes:

```text
[309.65, 97.70]
```

---

## Key Pattern

This is a simple **Mathematical Formula + Array** problem.

The general approach is:

```text
Input
  ↓
Apply formula 1 → Store at index 0
  ↓
Apply formula 2 → Store at index 1
  ↓
Return array
```
