# Sum of Multiples

## Problem

Given an integer `n`, return the sum of all integers from `1` to `n` that are divisible by **3, 5, or 7**.

### Example

**Input:**

```text
n = 10
```

Numbers divisible by `3`, `5`, or `7` are:

```text
3, 5, 6, 7, 9, 10
```

Their sum is:

```text
3 + 5 + 6 + 7 + 9 + 10 = 40
```

**Output:**

```text
40
```

---

## Approach

We loop through every number from `1` to `n`.

For each number, we check whether it is divisible by:

* `3`
* `5`
* `7`

We use the modulo operator `%`.

```java
i % 3 == 0
```

means:

> `i` is divisible by `3`.

Since a number only needs to satisfy **one** of the conditions, we use the OR operator `||`.

```java
if((i % 3 == 0) || (i % 5 == 0) || (i % 7 == 0))
```

If the condition is true, we add the number to `sum`.

---

## Code

```java
class Solution {

    public int sumOfMultiples(int n) {

        int sum = 0;

        for(int i = 1; i <= n; i++) {

            if((i % 3 == 0) || (i % 5 == 0) || (i % 7 == 0)) {

                sum += i;
            }
        }

        return sum;
    }
}
```

# Is There a Better Solution?

Yes, there is a **mathematical approach**, but it is not necessarily better for learning.

Your solution:

```text
Time:  O(n)
Space: O(1)
```

We can use **inclusion-exclusion** to calculate the answer without checking every number.

## Mathematical Approach

We need the sum of numbers divisible by:

```text
3 OR 5 OR 7
```

First calculate:

```text
sum of multiples of 3
+ sum of multiples of 5
+ sum of multiples of 7
```

But numbers divisible by two of them get counted twice.

For example:

```text
15
```

is divisible by both `3` and `5`.

So we subtract the sums of multiples of:

```text
3 × 5 = 15
3 × 7 = 21
5 × 7 = 35
```

However, numbers divisible by all three were subtracted too many times, so we add them back.

The LCM of `3, 5, 7` is:

```text
105
```

So the formula becomes:

```text
sum(3) + sum(5) + sum(7)
- sum(15) - sum(21) - sum(35)
+ sum(105)
```

---

## Sum of Multiples Formula

To find the sum of multiples of `d` up to `n`:

```text
d + 2d + 3d + ... + kd
```

where:

```text
k = n / d
```

Using:

```text
1 + 2 + 3 + ... + k = k(k + 1) / 2
```

we get:

```text
sum of multiples of d
= d × k × (k + 1) / 2
```

---

## Mathematical Code

```java
class Solution {

    public int sumOfMultiples(int n) {

        return sum(n, 3)
             + sum(n, 5)
             + sum(n, 7)
             - sum(n, 15)
             - sum(n, 21)
             - sum(n, 35)
             + sum(n, 105);
    }

    private int sum(int n, int d) {

        int k = n / d;

        return d * k * (k + 1) / 2;
    }
}
```

### Complexity

```text
Time:  O(1)
Space: O(1)
```

# Which Should You Use?

| Approach            |   Time |  Space | Difficulty            |
| ------------------- | -----: | -----: | --------------------- |
| Your loop           | `O(n)` | `O(1)` | ⭐ Easy                |
| Inclusion-Exclusion | `O(1)` | `O(1)` | ⭐⭐⭐ More mathematical |

### For your DSA practice

**Keep your current solution.** It is cleaner and demonstrates an important beginner pattern:

```text
Loop → Check condition → Process
```

The `O(1)` mathematical solution is useful to know, but it introduces **inclusion-exclusion + arithmetic series**, which is unnecessary if the constraints allow `O(n)`.

So I would consider your current solution the **better practical solution for learning and readability**, even though the mathematical solution has a better asymptotic time complexity.
