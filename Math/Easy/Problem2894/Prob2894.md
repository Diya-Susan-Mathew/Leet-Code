# Difference of Sums

## Problem
Given two integers `n` and `m`, calculate the difference between:

- The sum of all integers from `1` to `n` that are **not divisible by `m`**.
- The sum of all integers from `1` to `n` that **are divisible by `m`**.

Return:

`notDivSum - divisibleSum`

## Java Solution

```java
class Solution {
    public int differenceOfSums(int n, int m) {
        int divisibleSum = 0, notDivSum = 0;
        for (int i = 1; i <= n; i++) {
            if (i % m == 0) {
                divisibleSum += i;
            } else {
                notDivSum += i;
            }
        }
        return notDivSum - divisibleSum;
    }
}
```

## Explanation

1. Initialize two variables:
   - `divisibleSum` stores the sum of numbers divisible by `m`.
   - `notDivSum` stores the sum of numbers not divisible by `m`.
2. Iterate through every integer from `1` to `n`.
3. Use `i % m == 0` to check whether the current number is divisible by `m`.
   - If true, add `i` to `divisibleSum`.
   - Otherwise, add `i` to `notDivSum`.
4. Return `notDivSum - divisibleSum`.

## Example

**Input:** `n = 10, m = 3`

Numbers from `1` to `10`:

- Divisible by `3`: `3, 6, 9`
- Not divisible by `3`: `1, 2, 4, 5, 7, 8, 10`

Calculations:

- `divisibleSum = 3 + 6 + 9 = 18`
- `notDivSum = 1 + 2 + 4 + 5 + 7 + 8 + 10 = 37`
- Result = `37 - 18 = 19`

**Output:** `19`

## Complexity Analysis

Let `n` be the given upper limit.

- **Time Complexity:** `O(n)` — the loop visits each integer from `1` to `n` exactly once.
- **Space Complexity:** `O(1)` — only two variables are used, regardless of the input size.

## Key Concept

The modulo operator (`%`) gives the remainder after division. A number is divisible by `m` when its remainder is `0`.
