# Sum of the Digits of a Harshad Number

## Problem Explanation

Given an integer `x`, calculate the sum of its digits.

A number is called a **Harshad number** if it is divisible by the sum of
its digits.

-   If `x` is divisible by the sum of its digits, return the digit sum.
-   Otherwise, return `-1`.

## Examples

### Example 1

**Input:**

``` text
x = 18
```

**Explanation:**

The digits of `18` are `1` and `8`.

``` text
Digit sum = 1 + 8 = 9
18 % 9 = 0
```

Since `18` is divisible by `9`, it is a Harshad number.

**Output:**

``` text
9
```

### Example 2

**Input:**

``` text
x = 23
```

**Explanation:**

``` text
Digit sum = 2 + 3 = 5
23 % 5 = 3
```

Since the remainder is not `0`, `23` is not a Harshad number.

**Output:**

``` text
-1
```

### Example 3

**Input:**

``` text
x = 1
```

**Explanation:**

``` text
Digit sum = 1
1 % 1 = 0
```

Since `1` is divisible by its digit sum, return `1`.

**Output:**

``` text
1
```

## Java Solution

``` java
class Solution {
    public int sumOfTheDigitsOfHarshadNumber(int x) {
        int origNo = x;
        int sum = 0;

        while (x != 0) {
            int digit = x % 10;
            sum += digit;
            x = x / 10;
        }

        return origNo % sum == 0 ? sum : -1;
    }
}
```

## Code Walkthrough

### 1. Preserve the original number

``` java
int origNo = x;
```

The value of `x` will be changed while extracting its digits. We save
the original number in `origNo` so that we can check divisibility after
calculating the digit sum.

### 2. Initialize the digit sum

``` java
int sum = 0;
```

This variable stores the sum of all digits.

### 3. Extract and add each digit

``` java
while (x != 0) {
    int digit = x % 10;
    sum += digit;
    x = x / 10;
}
```

-   `x % 10` extracts the last digit.
-   `sum += digit` adds that digit to the sum.
-   `x / 10` removes the last digit.

For example, if `x = 18`:

  Iteration     `x`   `x % 10`   `sum` after addition   `x / 10`
  ----------- ----- ---------- ---------------------- ----------
  1              18          8                      8          1
  2               1          1                      9          0

The loop stops when `x` becomes `0`.

### 4. Check whether it is a Harshad number

``` java
return origNo % sum == 0 ? sum : -1;
```

-   If the original number is divisible by the digit sum, return `sum`.
-   Otherwise, return `-1`.

The ternary operator is equivalent to:

``` java
if (origNo % sum == 0) {
    return sum;
} else {
    return -1;
}
```

## Complexity Analysis

Let `d` be the number of digits in `x`.

-   **Time Complexity: `O(d)`** --- The loop processes each digit
    exactly once.
-   **Space Complexity: `O(1)`** --- Only a fixed number of variables
    are used.

Since the number of digits is proportional to `log10(x)`, the time
complexity can also be written as **`O(log x)`** for positive `x`.

## Key Concepts Used

-   Modulo operator (`%`) to extract the last digit.
-   Integer division (`/`) to remove the last digit.
-   Digit sum calculation.
-   Divisibility check.
-   Ternary operator.

## Important Observation

The original number must be preserved because the loop changes `x` until
it becomes `0`. Using `origNo` ensures that the divisibility check is
performed on the original input.
