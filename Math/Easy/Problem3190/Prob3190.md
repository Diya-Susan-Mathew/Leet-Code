# Minimum Operations

## Problem Understanding

Given an integer array `nums`, find the minimum number of operations
needed to make every element divisible by `3`.

In one operation, you can increase or decrease an element by `1`.

An element already divisible by `3` needs **0 operations**. An element
that is not divisible by `3` needs **1 operation**, because it can be
adjusted to the nearest multiple of `3`.

Therefore, the answer is simply the count of elements for which
`nums[i] % 3 != 0`.

## My Solution

``` java
class Solution {
    public int minimumOperations(int[] nums) {
        int op = 0;
        for (int i = 0; i < nums.length; i++) {
            if ((nums[i] % 3) != 0) {
                op++;
            }
        }
        return op;
    }
}
```

### How It Works

1.  Initialize `op` to `0`.
2.  Traverse every element in the array.
3.  Check whether the element is divisible by `3` using `nums[i] % 3`.
4.  If the remainder is not `0`, increment `op`.
5.  Return `op` after checking all elements.

### Example

**Input:**

``` text
nums = [1, 2, 3, 4]
```

    Element   Remainder when divided by 3   Operations needed
  --------- ----------------------------- -------------------
          1                             1                   1
          2                             2                   1
          3                             0                   0
          4                             1                   1

**Output:**

``` text
3
```

The elements `1`, `2`, and `4` each need one operation. The element `3`
already is divisible by `3`.

## Cleaner Code

``` java
class Solution {
    public int minimumOperations(int[] nums) {
        int operations = 0;

        for (int num : nums) {
            if (num % 3 != 0) {
                operations++;
            }
        }

        return operations;
    }
}
```

### What Changed?

-   Replaced the indexed `for` loop with an enhanced `for` loop
    (`for-each`).
-   Removed unnecessary parentheses around `num % 3 != 0`.
-   Used the descriptive variable name `operations`.

This version is cleaner and avoids using an index when the index is not
needed. It does **not** improve the asymptotic time complexity; both
solutions are already optimal.

## Complexity Analysis

Let `n` be the number of elements in `nums`.

-   **Time Complexity:** `O(n)` --- each element is checked exactly
    once.
-   **Space Complexity:** `O(1)` --- only one counter variable is used.

## Key Takeaway

Whenever the task is to count elements that satisfy a condition, a
single traversal is usually sufficient. Here, checking `num % 3 != 0`
tells us whether an element needs one operation.
