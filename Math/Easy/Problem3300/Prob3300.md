# Minimum Element After Digit Sum

## 1. Problem Understanding

You are given an integer array `nums`.

For every number in the array:

1.  Find the sum of its digits.
2.  Compare that digit sum with the digit sums of the other numbers.
3.  Return the **smallest digit sum**.

### Example 1

**Input:**

``` text
nums = [10, 12, 13, 14]
```

Digit sums:

-   `10` → `1 + 0 = 1`
-   `12` → `1 + 2 = 3`
-   `13` → `1 + 3 = 4`
-   `14` → `1 + 4 = 5`

The smallest digit sum is `1`.

**Output:**

``` text
1
```

### Example 2

**Input:**

``` text
nums = [99, 45, 23]
```

Digit sums:

-   `99` → `9 + 9 = 18`
-   `45` → `4 + 5 = 9`
-   `23` → `2 + 3 = 5`

The smallest digit sum is `5`.

**Output:**

``` text
5
```

## 2. My Original Solution

``` java
class Solution {
    public int minElement(int[] nums) {
        int minElement = Integer.MAX_VALUE;

        for (int i = 0; i < nums.length; i++) {
            int elem = nums[0];
            int sum = findSum(elem);
            minElement = Math.min(sum, minElement);
        }

        return minElement;
    }

    public int findSum(int eleme) {
        int sum1 = 0;

        while (eleme != 0) {
            int digit = eleme % 10;
            sum1 += digit;
            eleme = eleme / 10;
        }

        return sum1;
    }
}
```

### What is good about my approach?

-   I used `Integer.MAX_VALUE` to initialize the minimum.
-   I separated digit-sum calculation into a helper method, `findSum()`.
-   I used `Math.min()` to update the minimum value.

### What is the mistake?

Inside the `for` loop, I wrote:

``` java
int elem = nums[0];
```

This always selects the **first element** of the array.

Even though the loop runs for every index, it calculates the digit sum
of `nums[0]` repeatedly. It never processes the remaining elements.

### Correction

Use:

``` java
int elem = nums[i];
```

Now the loop processes the element at the current index.

## 3. Clean Version

``` java
class Solution {
    public int minElement(int[] nums) {
        int minElement = Integer.MAX_VALUE;

        for (int num : nums) {
            int sum = 0;

            while (num > 0) {
                sum += num % 10;
                num /= 10;
            }

            if (sum < minElement) {
                minElement = sum;
            }
        }

        return minElement;
    }
}
```

### How does the clean version work?

#### Step 1: Initialize the minimum

``` java
int minElement = Integer.MAX_VALUE;
```

We start with the largest possible integer so that the first digit sum
will replace it.

#### Step 2: Traverse the array using an enhanced for loop

``` java
for (int num : nums)
```

This is an enhanced `for` loop, also called a **for-each loop**.

It takes each element from the array one by one.

For example, if:

``` java
nums = [12, 45, 23]
```

The variable `num` takes the values `12`, `45`, and `23` in sequence.

#### Step 3: Calculate the digit sum

``` java
int sum = 0;

while (num > 0) {
    sum += num % 10;
    num /= 10;
}
```

Two important operations are used here:

-   `num % 10` extracts the last digit.
-   `num / 10` removes the last digit (integer division).

For example, consider `num = 123`:

  Iteration     `num % 10`   `sum`   `num / 10`
  ----------- ------------ ------- ------------
  1                      3       3           12
  2                      2       5            1
  3                      1       6            0

The final digit sum is `6`.

#### Step 4: Update the minimum

``` java
if (sum < minElement) {
    minElement = sum;
}
```

If the current digit sum is smaller than the minimum found so far,
update `minElement`.

#### Step 5: Return the answer

``` java
return minElement;
```

After processing all elements, `minElement` contains the smallest digit
sum.

## 4. Important Java Concepts

### `Integer.MAX_VALUE`

Represents the maximum value an `int` can store in Java:

``` java
int minElement = Integer.MAX_VALUE;
```

It is useful when finding a minimum because any smaller valid digit sum
will replace it.

### Enhanced for loop

Instead of using an index:

``` java
for (int i = 0; i < nums.length; i++) {
    int num = nums[i];
}
```

We can directly access each element:

``` java
for (int num : nums) {
    // Process num
}
```

Use an enhanced for loop when you only need the array values and do not
need their indices.

### Modulo operator (`%`)

The modulo operator returns the remainder.

``` java
123 % 10 = 3
```

It is commonly used to extract the last digit of a number.

### Integer division (`/`)

When both operands are integers, Java performs integer division:

``` java
123 / 10 = 12
```

This removes the last digit.

## 5. Complexity Analysis

Let:

-   `n` = number of elements in the array.
-   `d` = maximum number of digits in any element.

  -----------------------------------------------------------------------
  Complexity              Value                   Reason
  ----------------------- ----------------------- -----------------------
  Time                    `O(n × d)`              Each of the `n` numbers
                                                  is processed digit by
                                                  digit.

  Auxiliary space         `O(1)`                  Only a few variables
                                                  are used.
  -----------------------------------------------------------------------

Since the number of digits is determined by the size of the integer, the
solution uses constant auxiliary space.

## 6. Key Takeaway

My original approach had the right overall idea: calculate each digit
sum and maintain the minimum.

The main bug was selecting `nums[0]` instead of `nums[i]`, which caused
the first element to be processed repeatedly.

The clean version improves readability by:

-   Using an enhanced `for` loop.
-   Calculating the digit sum directly inside the loop.
-   Updating the minimum with a simple `if` condition.

**Remember:** When iterating through an array, make sure you are
processing the current element---not repeatedly accessing the first
element.

> Note: The clean version uses `while (num > 0)`, which is suitable when
> the input contains positive integers. If zero or negative values are
> allowed, the digit-sum logic should be adjusted accordingly.
