# Find Closest Person

## Problem Explanation

You are given three integers:

-   `x`: Starting position of Person 1.
-   `y`: Starting position of Person 2.
-   `z`: Position of the destination.

Both people move towards the destination at the **same speed**. Your
task is to determine who reaches the destination first.

Return:

-   `1` if Person 1 is closer to the destination.
-   `2` if Person 2 is closer to the destination.
-   `0` if both people are at the same distance from the destination.

In other words, compare the distances from `x` to `z` and from `y` to
`z`.

## Examples

### Example 1

**Input:**

``` text
x = 2, y = 7, z = 4
```

**Explanation:**

-   Person 1's distance: `|2 - 4| = 2`
-   Person 2's distance: `|7 - 4| = 3`

Person 1 is closer to the destination, so the answer is `1`.

**Output:**

``` text
1
```

### Example 2

**Input:**

``` text
x = 2, y = 5, z = 4
```

**Explanation:**

-   Person 1's distance: `|2 - 4| = 2`
-   Person 2's distance: `|5 - 4| = 1`

Person 2 is closer to the destination, so the answer is `2`.

**Output:**

``` text
2
```

### Example 3

**Input:**

``` text
x = 2, y = 6, z = 4
```

**Explanation:**

-   Person 1's distance: `|2 - 4| = 2`
-   Person 2's distance: `|6 - 4| = 2`

Both people are at the same distance from the destination, so the answer
is `0`.

**Output:**

``` text
0
```

## Your Java Solution

``` java
class Solution {
    public int findClosest(int x, int y, int z) {
        int diff1 = Math.abs(x - z);
        int diff2 = Math.abs(y - z);

        if (diff1 < diff2) {
            return 1;
        } else if (diff1 > diff2) {
            return 2;
        } else {
            return 0;
        }
    }
}
```

## How the Code Works

1.  `Math.abs(x - z)` calculates the distance between Person 1 and the
    destination. `Math.abs()` returns the absolute value, so the
    distance is never negative.
2.  `Math.abs(y - z)` calculates the distance between Person 2 and the
    destination.
3.  The `if` condition checks whether Person 1's distance is smaller. If
    it is, return `1`.
4.  The `else if` condition checks whether Person 2's distance is
    smaller. If it is, return `2`.
5.  If neither distance is smaller, the distances are equal, so return
    `0`.

## Dry Run

Consider `x = 2`, `y = 6`, and `z = 4`.

  Variable           Calculation   Value
  ---------- ------------------- -------
  `diff1`      `Math.abs(2 - 4)`     `2`
  `diff2`      `Math.abs(6 - 4)`     `2`

-   Is `diff1 < diff2`? No.
-   Is `diff1 > diff2`? No.
-   Therefore, both distances are equal, and the method returns `0`.

## Complexity Analysis

Let the input consist of the three integers `x`, `y`, and `z`.

-   **Time Complexity: O(1)** --- Only two distance calculations and a
    fixed number of comparisons are performed.
-   **Space Complexity: O(1)** --- Only two integer variables are used,
    regardless of the input values.

## Key Concept

The important idea is to compare **absolute distances**, not the numbers
themselves. A person can be on either side of the destination, so
`Math.abs()` ensures that the distance is always non-negative.
