# Mirror Distance

## Problem

Given an integer `n`, reverse its digits and calculate the absolute
difference between the original number and its reversed number.

In other words:

\[ `\text{Mirror Distance}`{=tex} = \|n - `\text{reverse}`{=tex}(n)\| \]

## Java Solution

``` java
class Solution {
    public int mirrorDistance(int n) {
        int original = n;
        int rev = 0;

        while (n != 0) {
            int digit = n % 10;
            rev = rev * 10 + digit;
            n = n / 10;
        }

        return Math.abs(original - rev);
    }
}
```

## Approach: Digit Reversal

1.  Store the original number in `original`, because `n` will be
    modified while reversing it.
2.  Initialize `rev = 0` to build the reversed number.
3.  Repeat while `n != 0`:
    -   `n % 10` extracts the last digit.
    -   `rev * 10 + digit` appends that digit to the reversed number.
    -   `n / 10` removes the last digit from `n`.
4.  Return `Math.abs(original - rev)` to get the absolute difference.

## Example Walkthrough

Suppose:

``` text
n = 123
```

  Iteration     `n`   `digit = n % 10`   `rev = rev * 10 + digit`
  ----------- ----- ------------------ --------------------------
  1             123                  3                          3
  2              12                  2                         32
  3               1                  1                        321

The reversed number is `321`.

``` text
Original number = 123
Reversed number = 321

Mirror Distance = |123 - 321|
                = 198
```

**Output:** `198`

## Complexity Analysis

-   **Time Complexity: (O(d))** --- Each digit is processed exactly
    once, where `d` is the number of digits in `n`.
-   **Space Complexity: (O(1))** --- Only a fixed number of variables
    are used.

## Important Java Concepts

-   `% 10`: Gets the last digit of a number.
-   `/ 10`: Removes the last digit when using integer division.
-   `rev * 10 + digit`: Adds a digit to the end of the reversed number.
-   `Math.abs()`: Returns the absolute value, ensuring the result is
    non-negative.
