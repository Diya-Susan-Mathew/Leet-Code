# Digit Frequency Score

## Java Solution

``` java
class Solution {
    public int digitFrequencyScore(int n) {
        int sum = 0;

        while (n != 0) {
            int digit = n % 10;
            sum += digit;
            n = n / 10;
        }

        return sum;
    }
}
```

## Explanation

The method calculates the **sum of the digits** of the given integer.

1.  Initialize `sum` to `0`.
2.  Use `n % 10` to extract the last digit.
3.  Add that digit to `sum`.
4.  Use `n / 10` to remove the last digit.
5.  Repeat until `n` becomes `0`.
6.  Return the sum.

## Example

For `n = 527`:

-   Extract `7`: `sum = 7`, `n = 52`
-   Extract `2`: `sum = 9`, `n = 5`
-   Extract `5`: `sum = 14`, `n = 0`

**Output:** `14`

## Complexity Analysis

-   **Time Complexity:** `O(d)`, where `d` is the number of digits in
    `n`. Each loop iteration processes one digit.
-   **Space Complexity:** `O(1)`, because only a fixed number of
    variables are used.

> Note: Despite the method name `digitFrequencyScore`, this
> implementation calculates the sum of the digits, not the frequency of
> each digit.
