# Check if Number is a Sum of Powers of Three

## Approach

The key observation is that every number can be represented in **base 3 (ternary)**.

- If a number can be expressed as the **sum of distinct powers of 3**, then its ternary representation can only contain the digits **0** and **1**.
- If any digit in its base-3 representation is **2**, it means that power of 3 would need to be used more than once, which is not allowed.

### Algorithm

1. While `n` is greater than `0`:
   - Check the remainder when dividing by `3` (`n % 3`).
   - If the remainder is `2`, return `false`.
   - Otherwise, divide `n` by `3` and continue.
2. If the loop finishes without finding a remainder of `2`, return `true`.

## Java Solution

```java
class Solution {
    public boolean checkPowersOfThree(int n) {
        while (n > 0) {
            if (n % 3 == 2) {
                return false;
            }
            n = n / 3;
        }
        return true;
    }
}
```

## Complexity Analysis

- **Time Complexity:** **O(log₃ n)**
  - In each iteration, `n` is divided by `3`, so the number of iterations is proportional to `log₃ n`.

- **Space Complexity:** **O(1)**
  - Only a few variables are used, regardless of the input size.

## Key Insight

- A number is a sum of **distinct powers of 3** **if and only if** its base-3 representation contains only the digits **0** and **1**.
- Encountering a digit **2** immediately proves that the number cannot be represented as a sum of distinct powers of 3.
- This avoids generating powers of 3 or using backtracking, resulting in a simple and efficient logarithmic-time solution.
