Naive Approach 
class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        int n = temperatures.length;
        int[] answer = new int[n]; // Initialized with 0s by default
        
        // Loop through each day
        for (int i = 0; i < n; i++) {
            // Check all future days
            for (int j = i + 1; j < n; j++) {
                // If a warmer day is found
                if (temperatures[j] > temperatures[i]) {
                    answer[i] = j - i; // Calculate the distance in days
                    break;             // Stop searching for this day
                }
            }
        }
        
        return answer;
    }
}


Why this will fail on LeetCode (Time Limit Exceeded)
Time Complexity: O(N²) because for every day, you potentially scan the rest of the array.
If the temperatures are strictly decreasing (e.g., [90, 80, 70, 60]), the inner loop runs N times for almost every element.
Space Complexity: O(1) auxiliary space (excluding the output array).
