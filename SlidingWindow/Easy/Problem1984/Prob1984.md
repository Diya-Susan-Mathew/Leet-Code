# LeetCode 1984 — Minimum Difference Between Highest and Lowest of K Scores

## Pattern Used
**Sorting + Fixed-Size Sliding Window**

## Approach

1. Sort the array in ascending order.
2. Consider every group of `k` consecutive elements.
3. Since the array is sorted:
   - `nums[i]` is the minimum element.
   - `nums[i + k - 1]` is the maximum element.
4. Calculate the difference between the maximum and minimum.
5. Keep track of the minimum difference.

## Code

```java
class Solution {
    public int minimumDifference(int[] nums, int k) {
        Arrays.sort(nums);

        int minDiff = Integer.MAX_VALUE;

        for (int i = 0; i <= nums.length - k; i++) {
            int diff = nums[i + k - 1] - nums[i];

            minDiff = Math.min(minDiff, diff);
        }

        return minDiff;
    }
}
```

## Why `i + k - 1`?

If the window starts at index `i` and contains `k` elements, the last index is:

`i + k - 1`

For example, if `i = 1` and `k = 3`, the window contains indices `1, 2, 3`.

Therefore:

```java
nums[i + k - 1] - nums[i]
```

gives the maximum minus minimum for the current window.

## Complexity Analysis

### Time Complexity
`O(n log n)`

- Sorting takes `O(n log n)`.
- The loop takes `O(n)`.
- Overall: `O(n log n)`.

### Space Complexity
`O(1)` extra space, apart from the space used internally by the sorting algorithm.

## Key Pattern

**Sort → Fixed-Size Window → Compare First and Last Elements**
