# LeetCode 2379 — Minimum Recolors to Get K Consecutive Black Blocks

**Approach Used:** Sliding Window

## Problem

Given a string `blocks` containing `'B'` (black) and `'W'` (white), and an integer `k`, find the minimum number of white blocks that need to be recolored black so that there are `k` consecutive black blocks.

## Approach: Sliding Window

The key observation is that we do not actually need to recolor the blocks.

For every window of size `k`, the number of white blocks inside that window tells us exactly how many recolors are required to make all `k` blocks black.

So, we use a **sliding window** of size `k`:

1. Count the number of `'W'` blocks in the first window of size `k`.
2. Store this count as `minW`.
3. Move the window one position at a time.
4. When the window moves:
   - Add the new block entering the window.
   - Remove the old block leaving the window.
5. Update `minW` with the smallest number of white blocks found.
6. Return `minW`.

### Why does this work?

Suppose a window of size `k` contains:

```text
B W W B B
```

If `k = 5`, there are `2` white blocks.

Therefore, we need exactly `2` recolors to obtain:

```text
B B B B B
```

So the answer is simply the **minimum number of white blocks in any window of size `k`**.

## Code Explanation

### 1. Count white blocks in the first window

```java
int countW = 0;

for(int i = 0; i < k; i++){
    if(blocks.charAt(i) == 'W'){
        countW++;
    }
}
```

This calculates the number of white blocks in the first window of size `k`.

### 2. Initialize the minimum

```java
int minW = countW;
```

The first window is currently our best answer.

### 3. Slide the window

```java
for(int i = k; i < blocks.length(); i++){
```

Here, `i` represents the new block entering the window.

#### Add the entering block

```java
if(blocks.charAt(i) == 'W'){
    countW++;
}
```

If the new block is white, increase `countW`.

#### Remove the leaving block

```java
if(blocks.charAt(i-k) == 'W'){
    countW--;
}
```

The block at `i-k` is leaving the window.

If it was white, decrease `countW`.

### 4. Update the minimum

```java
minW = Math.min(minW, countW);
```

Keep track of the smallest number of white blocks found in any window of size `k`.

## Example

Consider:

```text
blocks = "WBBWWBB"
k = 3
```

Windows of size `3`:

```text
WBB → 1 W
BBW → 1 W
BWW → 2 W
WWB → 2 W
WBB → 1 W
```

The minimum number of white blocks is:

```text
1
```

Therefore, the answer is `1`.

## Complexity Analysis

Let `n` be the length of `blocks`.

### Time Complexity

**O(n)**

- The first loop processes the first `k` elements.
- The second loop processes the remaining `n-k` elements.
- Each element is added to and removed from the sliding window at most once.

Therefore, the overall time complexity is:

```text
O(k + (n-k)) = O(n)
```

### Space Complexity

**O(1)**

Only a few variables are used:

```text
countW
minW
i
```

No additional array, HashMap, or other data structure is required.

## Pattern to Remember

**Fixed-Size Sliding Window**

Whenever a problem asks you to:

- Examine every contiguous subarray/substring of a fixed size `k`
- Find a minimum/maximum/count/sum
- Avoid recalculating the entire window each time

think:

> **Sliding Window — add the new element, remove the old element.**

For this problem:

```text
Window size = k
Window value = number of W's
Goal = minimum number of W's
```
