# LeetCode 1297 — Maximum Number of Occurrences of a Substring

## Problem

Given a string `s`, find the maximum number of occurrences of any substring that satisfies:

- The substring length is exactly `minSize`.
- It contains at most `maxLetters` unique characters.
- The substring can occur multiple times in `s`.

The problem also gives `maxSize`, but we don't actually need to use it.

---

## Example

```text
Input:
s = "aababcaab"
maxLetters = 2
minSize = 3
maxSize = 4

Output:
2

- `n` = length of the string `s`
