# LeetCode 1456 — Maximum Number of Vowels in a Substring of Given Length

## Pattern Used

**Sliding Window — Fixed-Size Window**

## Problem

Given a string `s` and an integer `k`, find the **maximum number of vowels** in any substring of length `k`.

The vowels are:

```text
a, e, i, o, u
```

### Example

```text
Input:  s = "abciiidef"
        k = 3

Output: 3
```

The substring `"iii"` contains 3 vowels.

## Approach

Since the substring must always have exactly `k` characters, this is a **fixed-size sliding window** problem.

Instead of counting the vowels in every substring separately:

1. Count the vowels in the first window of size `k`.
2. Slide the window one character at a time.
3. Add the new character entering the window.
4. Remove the character leaving the window.
5. Keep track of the maximum number of vowels.

The important idea is:

```text
Add the new character
        ↓
Remove the old character
        ↓
Update maximum
```

This avoids recounting the entire window each time.

## Code

```java
class Solution {
    public int maxVowels(String s, int k) {
        int countVowels = 0;

        // Count vowels in the first window
        for (int i = 0; i < k; i++) {
            if (s.charAt(i) == 'a' || s.charAt(i) == 'e' ||
                s.charAt(i) == 'i' || s.charAt(i) == 'o' ||
                s.charAt(i) == 'u') {
                countVowels++;
            }
        }

        int maxCount = countVowels;

        // Slide the window
        for (int i = k; i < s.length(); i++) {

            // Add the new character
            if (s.charAt(i) == 'a' || s.charAt(i) == 'e' ||
                s.charAt(i) == 'i' || s.charAt(i) == 'o' ||
                s.charAt(i) == 'u') {
                countVowels++;
            }

            // Remove the character leaving the window
            if (s.charAt(i - k) == 'a' || s.charAt(i - k) == 'e' ||
                s.charAt(i - k) == 'i' || s.charAt(i - k) == 'o' ||
                s.charAt(i - k) == 'u') {
                countVowels--;
            }

            maxCount = Math.max(countVowels, maxCount);
        }

        return maxCount;
    }
}
```

## Key Sliding Window Pattern

This is a **fixed-size sliding window** because the window always contains exactly `k` characters.

```text
Initial window:
[k characters]

Slide:
Remove → Add → Update answer
```

For example:

```text
s = "abciiidef"
k = 3

[abc] iiidef
 a[ b c i ]i d e f
 ab[ c i i ]d e f
 ...
```

Instead of recalculating the number of vowels in every window, we only update the count when a character enters or leaves.

## Complexity Analysis

- **Time Complexity:** `O(n)` — We process each character at most once.
- **Space Complexity:** `O(1)` — Only a few variables are used.

## Important Observation

The main advantage of the sliding window is that we **reuse the previous window's information**.

Instead of:

```text
Count all k characters again
```

we do:

```text
Previous count
+ new character
- removed character
= current count
```

> **Remember: Fixed window → Add incoming element → Remove outgoing element → Update answer.**
