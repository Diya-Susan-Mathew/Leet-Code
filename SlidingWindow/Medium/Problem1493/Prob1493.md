# LeetCode 1493 — Longest Subarray of 1's After Deleting One Element

## Approach
Use a **Sliding Window** with at most one `0`.

- Maintain a window using `left` and `right`.
- Count the number of zeros in the current window.
- If `zeroCount > 1`, move `left` forward until the window has at most one zero.
- `right - left` gives the length after deleting one element.
- Keep track of the maximum length.

## Key Point
We use:

`right - left`

instead of `right - left + 1` because **one element must always be deleted**.

## Complexity
- **Time:** O(n)
- **Space:** O(1)

## Pattern
**Sliding Window**
