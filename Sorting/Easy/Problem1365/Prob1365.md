# Smaller Numbers Than Current

## 1. Brute Force Approach

### Approach
- For every element, compare it with every other element.
- Count how many numbers are strictly smaller.
- Store the count in `result`.

### Code
```java
class Solution {
    public int[] smallerNumbersThanCurrent(int[] nums) {
        int[] result = new int[nums.length];

        int k = 0;

        for(int i = 0; i < nums.length; i++) {
            int count = 0;
            int currentNum = nums[i];

            for(int j = 0; j < nums.length; j++) {
                if(currentNum > nums[j]) {
                    count++;
                }
            }

            result[k] = count;
            k++;
        }

        return result;
    }
}
```

### Complexity
- **Time:** `O(n²)`
- **Space:** `O(n)` for the result array

## 2. Optimal Approach — Counting Array + Prefix Sum

### Key Idea
Since `nums[i]` is limited to `0–100`, use a frequency array.

### Steps
1. Store the frequency of every number in `count`.
2. Convert `count` into a prefix sum array.
3. `count[x - 1]` gives the number of elements smaller than `x`.
4. If `x == 0`, there are no smaller numbers.

### Code
```java
class Solution {
    public int[] smallerNumbersThanCurrent(int[] nums) {
        int[] count = new int[101];
        int[] result = new int[nums.length];

        for(int num : nums) {
            count[num]++;
        }

        for(int i = 1; i < count.length; i++) {
            count[i] += count[i - 1];
        }

        for(int i = 0; i < nums.length; i++) {
            if(nums[i] == 0) {
                result[i] = 0;
            } else {
                result[i] = count[nums[i] - 1];
            }
        }

        return result;
    }
}
```

### Complexity
- **Time:** `O(n + 101)` → effectively `O(n)`
- **Space:** `O(101)` → effectively `O(1)` apart from the result array

---

## Key Pattern

### Frequency Array + Prefix Sum

Useful when:
- The values are integers.
- The value range is small and known.
- We need to count elements smaller or greater than a given value.

### Important Formula

```text
count[x - 1] = number of elements smaller than x
```

For example:

```text
x = 5

count[4] = number of elements ≤ 4
         = number of elements < 5
```

## Brute Force vs Optimal

| Approach | Time | Space | Main Idea |
|---|---:|---:|---|
| Brute Force | `O(n²)` | `O(n)` | Compare every pair |
| Counting + Prefix Sum | `O(n)` | `O(1)` | Frequency + prefix sum |
