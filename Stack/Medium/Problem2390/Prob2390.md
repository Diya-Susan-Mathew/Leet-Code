# Remove Stars From a String

## Approach

The idea is to simulate a stack using a `StringBuilder`.

1. Initialize an empty `StringBuilder`.
2. Traverse the string character by character.
3. For each character:
   - If it is **not** `'*'`, append it to the `StringBuilder` (similar to pushing onto a stack).
   - If it is `'*'`, remove the last character from the `StringBuilder` (similar to popping from a stack).
4. After processing all characters, the `StringBuilder` contains the final string.

Using `StringBuilder` avoids the overhead of an explicit stack while still providing efficient append and delete operations.

## Java Solution

```java
class Solution {
    public String removeStars(String s) {
        StringBuilder sb = new StringBuilder();

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);

            if (c == '*') {
                // Remove the last appended character
                sb.deleteCharAt(sb.length() - 1);
            } else {
                // Append the current character
                sb.append(c);
            }
        }

        return sb.toString();
    }
}
```

## Complexity Analysis

- **Time Complexity:** **O(n)**
  - Each character is processed exactly once.
  - Appending and deleting the last character in a `StringBuilder` are both **O(1)** amortized.
  - Overall complexity is **O(n)**.

- **Space Complexity:** **O(n)**
  - In the worst case (when there are no `'*'` characters), the `StringBuilder` stores all characters of the input string.

## Key Insight

- Treat the `StringBuilder` as a stack:
  - **Append** → Push
  - **Delete last character** → Pop
- Since every `'*'` removes the closest non-star character to its left, the stack approach naturally models the required behavior.
- `StringBuilder` provides a concise and efficient in-place implementation without needing an explicit `Stack<Character>`.
