# LeetCode 1221 — Split a String in Balanced Strings

## 1. Problem Statement

You are given a string `s` containing only the characters `'L'` and `'R'`.

Split the string into the **maximum number of balanced substrings**.

A substring is **balanced** if it contains an equal number of `L` and `R` characters.

Examples:

- `"LR"` is balanced: one `L` and one `R`.
- `"RLRL"` is balanced: two `R`s and two `L`s.
- `"LLRR"` is balanced: two `L`s and two `R`s.
- `"LLR"` is not balanced: two `L`s and one `R`.

**Important:** The substrings must be consecutive parts of the original string. You cannot rearrange the characters.

## 2. Example 1

**Input:**

```text
s = "RLRRLLRLRL"
```

One maximum split is:

```text
"RL" + "RRLL" + "RL" + "RL"
```

Each substring has the same number of `R` and `L` characters:

| Substring | Number of `R`s | Number of `L`s | Balanced? |
|---|---:|---:|---|
| `"RL"` | 1 | 1 | Yes |
| `"RRLL"` | 2 | 2 | Yes |
| `"RL"` | 1 | 1 | Yes |
| `"RL"` | 1 | 1 | Yes |

**Output:** `4`

There are four balanced substrings.

## 3. Example 2

**Input:**

```text
s = "LLLLRRRR"
```

There are four `L`s followed by four `R`s. The whole string is balanced, but it cannot be split into smaller balanced consecutive substrings because every `L` appears before every `R`.

So the maximum split is:

```text
"LLLLRRRR"
```

**Output:** `1`

This example shows why the order of the characters matters. You cannot rearrange them to make `"LLRR" + "LLRR"`.

## 4. Example 3

**Input:**

```text
s = "RLRL"
```

Split it into:

```text
"RL" + "RL"
```

Both substrings are balanced.

**Output:** `2`

## 5. My Solution

```java
class Solution {
    public int balancedStringSplit(String s) {
        int countR = 0, countL = 0, countBalanced = 0;

        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == 'R') {
                countR++;
            } else if (s.charAt(i) == 'L') {
                countL++;
            }

            if (countR == countL) {
                countBalanced++;
                countR = 0;
                countL = 0;
            }
        }

        return countBalanced;
    }
}
```

### How my solution works

- `countR` counts the `R` characters in the current segment.
- `countL` counts the `L` characters in the current segment.
- `countBalanced` records the number of balanced substrings found.
- When `countR == countL`, a balanced substring has been found. Increase `countBalanced` and reset both character counters to start counting the next segment.
- Return `countBalanced`.

## 6. Optimal Solution

```java
class Solution {
    public int balancedStringSplit(String s) {
        int balance = 0;
        int count = 0;

        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == 'R') {
                balance++;
            } else {
                balance--;
            }

            if (balance == 0) {
                count++;
            }
        }

        return count;
    }
}
```

### How the optimal solution works

- When the character is `'R'`, increment `balance`.
- When the character is `'L'`, decrement `balance`.
- When `balance == 0`, the current segment has equal numbers of `R` and `L`. Increment `count`.
- Return `count` after processing the string.

You do not need to reset `balance` explicitly. Whenever a balanced segment is found, `balance` is already `0`, so the next segment naturally starts from zero.

## 7. Step-by-Step Balance Example

For `s = "RLRRLLRLRL"`:

| Character | Balance after character | Balanced count |
|---|---:|---:|
| `R` | 1 | 0 |
| `L` | 0 | 1 |
| `R` | 1 | 1 |
| `R` | 2 | 1 |
| `L` | 1 | 1 |
| `L` | 0 | 2 |
| `R` | 1 | 2 |
| `L` | 0 | 3 |
| `R` | 1 | 3 |
| `L` | 0 | 4 |

The balance returns to zero four times, so the answer is `4`.

## 8. Complexity Analysis

Let `n` be the length of the string.

| Complexity | My solution | Optimal solution |
|---|---|---|
| Time complexity | `O(n)` | `O(n)` |
| Auxiliary space | `O(1)` | `O(1)` |

Both solutions are asymptotically optimal: each character is processed once, and each solution uses a constant number of integer variables.

## 9. Comparison of the Two Solutions

- **My solution:** Tracks the counts of `R` and `L` separately. When they are equal, it counts a balanced segment and resets both counters.
- **Optimal solution:** Tracks the difference between the counts using one `balance` variable. Whenever the balance becomes zero, it counts a balanced segment.

The optimal version is shorter and uses one fewer counter, but **both solutions are correct and have the same time and auxiliary-space complexity**.

## 10. Key Takeaway

This is a **greedy counting** problem. Count a balanced substring as soon as the running balance returns to zero. This produces the maximum number of balanced consecutive substrings.

The key pattern is:

```text
R -> balance + 1
L -> balance - 1
balance == 0 -> count one balanced substring
```
