# LeetCode 1816 - Truncate Sentence

## Problem Description

You are given a sentence `s` consisting of words separated by a single space and an integer `k`.

Your task is to return the sentence containing **only the first `k` words**. All remaining words should be removed.

A word is a sequence of characters separated by spaces.

### Example 1

**Input:**
```text
s = "Hello how are you Contestant", k = 4
```

**Output:**
```text
"Hello how are you"
```

**Explanation:**

The sentence contains five words:

1. `Hello`
2. `how`
3. `are`
4. `you`
5. `Contestant`

Since `k = 4`, we keep only the first four words and remove `Contestant`.

Therefore, the answer is `"Hello how are you"`.

### Example 2

**Input:**
```text
s = "What is the solution", k = 2
```

**Output:**
```text
"What is"
```

**Explanation:**

We need only the first two words: `What` and `is`.

Therefore, the answer is `"What is"`.

## Approach: Counting Spaces

Since the words are separated by a single space, we can identify the end of the first `k` words by counting spaces.

### Algorithm

1. Initialize `wordCount = 0`.
2. Traverse the string character by character.
3. Whenever a space is encountered, increment `wordCount`.
4. When `wordCount == k`, return the substring before the current space using `s.substring(0, i)`.
5. If the loop finishes without finding the required space, return the original string.

## Java Solution

```java
class Solution {
    public String truncateSentence(String s, int k) {
        int wordCount = 0;

        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == ' ') {
                wordCount++;
            }

            if (wordCount == k) {
                return s.substring(0, i);
            }
        }

        return s;
    }
}
```

## Complexity Analysis

- **Time Complexity:** \(O(n)\), where `n` is the length of the string. In the worst case, we traverse the entire sentence.
- **Space Complexity:** \(O(n)\) in the worst case for the returned substring, depending on the Java implementation.

## Key Concepts

- String traversal
- Counting spaces
- `substring()` method
- Early return

## Important Observation

If `k` is less than the total number of words, the `k`-th space marks the end of the first `k` words.

For example, when `k = 2`:

```text
"Java is easy to learn"
       ^
```

The second word ends just before the second space, so the returned substring is `"Java is"`.

If `k` equals the total number of words, there may be no `k`-th space. In that case, the method correctly returns the original sentence.
