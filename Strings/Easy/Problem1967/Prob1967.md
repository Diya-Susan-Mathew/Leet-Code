# Number of Strings That Appear as Substrings in Word

## Problem
Given an array of strings `patterns` and a string `word`, count how many strings in `patterns` appear as a substring of `word`.

## Java Solution

```java
class Solution {
    public int numOfStrings(String[] patterns, String word) {
        int count = 0;

        for (int i = 0; i < patterns.length; i++) {
            if (word.indexOf(patterns[i]) != -1) {
                count++;
            }
        }

        return count;
    }
}
```

## Explanation
- Initialize `count` to `0`.
- Iterate through every string in `patterns`.
- `word.indexOf(patterns[i])` returns the starting index of the pattern in `word`, or `-1` if it is not found.
- If the result is not `-1`, the pattern occurs in `word`, so increment `count`.
- Return `count` after checking all patterns.

## Complexity Analysis
Let:
- `n` be the number of strings in `patterns`.
- `m` be the length of `word`.
- `k` be the maximum length of a pattern.

- **Time Complexity:** Typically described as `O(n * m * k)` as a conservative bound for checking each pattern with substring search.
- **Space Complexity:** `O(1)` auxiliary space, excluding the input.
