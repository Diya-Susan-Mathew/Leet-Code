# LeetCode 2114: Maximum Number of Words Found in Sentences

## Problem

Given an array of strings `sentences`, return the maximum number of words in any sentence.

This file compares two approaches:

1. **Split approach:** Split each sentence into words and count them.
2. **Space-counting approach:** Count the spaces in each sentence. Since the problem's sentences use single spaces between words, the number of words is the number of spaces plus one.

> The second approach avoids creating a temporary array for each sentence. It is more space-efficient, though both approaches take linear time overall.

---

## Approach 1: Your Solution — Using `split()`

### Java Code

```java
class Solution {
    public int mostWordsFound(String[] sentences) {
        int maxLength = Integer.MIN_VALUE;

        for (int i = 0; i < sentences.length; i++) {
            String words[] = sentences[i].split("\\s+");
            maxLength = Math.max(maxLength, words.length);
        }

        return maxLength;
    }
}
```

### Explanation

1. Initialize `maxLength` to store the largest word count found so far.
2. Loop through each sentence using its index.
3. Use `split("\\s+")` to separate the sentence wherever one or more whitespace characters occur.
4. `words.length` gives the number of words in that sentence.
5. Use `Math.max()` to update the maximum word count.
6. Return `maxLength`.

You can also initialize `maxLength` to `0`, because a word count cannot be negative.

### Example

For the sentence:

```text
"alice and bob love leetcode"
```

`split("\\s+")` creates:

```text
["alice", "and", "bob", "love", "leetcode"]
```

There are `5` words.

### Complexity

Let `C` be the total number of characters across all sentences.

- **Time:** `O(C)` overall, because splitting processes the characters in the sentences.
- **Auxiliary space:** Up to `O(W)` for the temporary array of words in the current sentence, where `W` is its number of words.

## Approach 2: Count Spaces

### Java Code

```java
class Solution {
    public int mostWordsFound(String[] sentences) {
        int maxWords = 0;

        for (String sentence : sentences) {
            int spaceCount = 0;
            int len = sentence.length();

            for (int i = 0; i < len; i++) {
                if (sentence.charAt(i) == ' ') {
                    spaceCount++;
                }
            }

            maxWords = Math.max(maxWords, spaceCount + 1);
        }

        return maxWords;
    }
}
```

### Explanation

#### 1. Initialize the maximum word count

```java
int maxWords = 0;
```

This stores the highest number of words found in any sentence.

#### 2. Visit each sentence

```java
for (String sentence : sentences)
```

This is an enhanced `for` loop. It directly gives you each sentence without requiring an index into the array.

#### 3. Count spaces

```java
int spaceCount = 0;
int len = sentence.length();

for (int i = 0; i < len; i++) {
    if (sentence.charAt(i) == ' ') {
        spaceCount++;
    }
}
```

- `sentence.length()` returns the number of characters.
- `sentence.charAt(i)` gets the character at index `i`.
- Whenever that character is a space (`' '`), increment `spaceCount`.

#### 4. Calculate the number of words

```java
maxWords = Math.max(maxWords, spaceCount + 1);
```

If words are separated by single spaces, then:

**Number of words = Number of spaces + 1**

For example, `"i think so too"` has three spaces, so it contains `3 + 1 = 4` words.

#### 5. Return the answer

```java
return maxWords;
```

Returns the largest word count.

### Example Walkthrough

Input:

```text
sentences = [
    "alice and bob love leetcode",
    "i think so too",
    "this is great thanks very much"
]
```

| Sentence | Space count | Word count (`spaces + 1`) | Maximum so far |
|---|---:|---:|---:|
| `alice and bob love leetcode` | 4 | 5 | 5 |
| `i think so too` | 3 | 4 | 5 |
| `this is great thanks very much` | 5 | 6 | 6 |

Output:

```text
6
```

### Complexity

Let `C` be the total number of characters across all sentences.

- **Time:** `O(C)`, because each character is checked once.
- **Auxiliary space:** `O(1)`, because the algorithm uses only a few variables and does not create an array of words.

---

## Comparison

| Feature | Split approach | Space-counting approach |
|---|---|---|
| Main idea | Split sentence into words | Count spaces and add one |
| Extra word array | Yes | No |
| Time complexity | `O(C)` | `O(C)` |
| Auxiliary space | `O(W)` for the temporary word array | `O(1)` |
| Important assumption | `split("\\s+")` handles runs of whitespace | Words are separated by single spaces, as guaranteed by the problem |

## Key Idea to Remember

If a sentence has exactly one space between each pair of words:

`words = spaces + 1`

Counting spaces avoids creating a separate array of words and uses constant auxiliary space.
