# Check If All `a` Characters Appear Before All `b` Characters

## Problem

Given a string `s` containing only `'a'` and `'b'`, check whether all
occurrences of `'a'` appear before all occurrences of `'b'`.

Return `true` if no `'a'` appears after a `'b'`; otherwise, return
`false`.

## Java Code

``` java
class Solution {
    public boolean checkString(String s) {
        int index = -1;

        // Find the first occurrence of 'b'
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == 'a') {
                continue;
            } else {
                index = i;
                break;
            }
        }

        // Check whether an 'a' occurs after the first 'b'
        if (index != -1) {
            for (int i = index + 1; i < s.length(); i++) {
                if (s.charAt(i) == 'a') {
                    return false;
                }
            }
        }

        return true;
    }
}
```

## Example Test Cases

The following examples show how the method behaves for different inputs:

  Input `s`     Output   Explanation
  ------------ --------- ---------------------------------------------------
  `"aaabbb"`    `true`   All `a`s appear before the `b`s.
  `"aaa"`       `true`   There are no `b`s, so the condition is satisfied.
  `"bbb"`       `true`   There are no `a`s, so the condition is satisfied.
  `"ab"`        `true`   The `a` appears before the `b`.
  `"ba"`        `false`  An `a` appears after a `b`.
  `"aabab"`     `false`  An `a` appears after the first `b`.

### Running the Examples

You can test the `Solution` class using this `main` method:

``` java
public class Main {
    public static void main(String[] args) {
        Solution sol = new Solution();

        System.out.println(sol.checkString("aaabbb")); // true
        System.out.println(sol.checkString("aaa"));    // true
        System.out.println(sol.checkString("bbb"));    // true
        System.out.println(sol.checkString("ab"));     // true
        System.out.println(sol.checkString("ba"));     // false
        System.out.println(sol.checkString("aabab"));  // false
    }
}
```

## Explanation

The approach uses two loops.

### 1. Find the first occurrence of `b`

``` java
int index = -1;

for (int i = 0; i < s.length(); i++) {
    if (s.charAt(i) == 'a') {
        continue;
    } else {
        index = i;
        break;
    }
}
```

-   Initially, `index` is `-1`, meaning that no `'b'` has been found.
-   The loop checks each character.
-   If the character is `'a'`, it continues to the next position.
-   Otherwise, it has found the first `'b'`. It stores that position in
    `index` and exits the loop using `break`.

### 2. Check for an `a` after the first `b`

``` java
if (index != -1) {
    for (int i = index + 1; i < s.length(); i++) {
        if (s.charAt(i) == 'a') {
            return false;
        }
    }
}
```

-   If `index` is not `-1`, a `'b'` was found.
-   Start checking from the position immediately after the first `'b'`.
-   If any later character is `'a'`, the order is invalid, so return
    `false`.

### 3. Return `true`

``` java
return true;
```

If no `'a'` is found after the first `'b'`, the string satisfies the
required order.

## Dry Run

Consider:

``` text
s = "aaabb"
```

**First loop:**

    `i`  `s.charAt(i)`  Action
  ----- --------------- ---------------------------
      0        a        Continue
      1        a        Continue
      2        a        Continue
      3        b        Set `index = 3` and break

Now, `index = 3`.

**Second loop:**

Start from `index + 1 = 4`.

    `i`  `s.charAt(i)`  Action
  ----- --------------- ----------------------
      4        b        Not an `a`; continue

No `'a'` is found after the first `'b'`, so the method returns `true`.

### Dry Run for a False Case

Consider:

``` text
s = "aabab"
```

-   The first `'b'` occurs at index `2`.
-   The second loop starts at index `3`.
-   `s.charAt(3)` is `'a'`.
-   Therefore, the method returns `false`.

## Complexity Analysis

Let `n` be the length of the string.

-   **Time Complexity: `O(n)`** --- The two loops together examine at
    most `n` characters.
-   **Space Complexity: `O(1)`** --- Only the integer variable `index`
    is used.

## Important Java Concept

  Expression      Meaning
  --------------- ------------------------
  `i`             Integer index
  `s.charAt(i)`   Character at index `i`
  `'a'`           Character literal
  `"a"`           String literal

When comparing a character in a Java string, use:

``` java
s.charAt(i) == 'a'
```
