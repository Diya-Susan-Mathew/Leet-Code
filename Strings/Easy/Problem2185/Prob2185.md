# Prefix Count

## Problem Explanation

You are given:

-   A string array `words`.
-   A string `pref`.

Your task is to count how many strings in `words` **start with** the
prefix `pref`.

A prefix is a sequence of characters that appears at the **beginning**
of a word, in the same order.

### Example 1

**Input:**

``` text
words = ["pay", "attention", "practice", "attend"]
pref = "at"
```

**Output:**

``` text
2
```

**Explanation:**

-   `"pay"` does not start with `"at"`.
-   `"attention"` starts with `"at"` --- count it.
-   `"practice"` does not start with `"at"`.
-   `"attend"` starts with `"at"` --- count it.

Therefore, the answer is `2`.

### Example 2

**Input:**

``` text
words = ["leetcode", "win", "loops", "success"]
pref = "code"
```

**Output:**

``` text
0
```

**Explanation:**

None of the words starts with `"code"`. Even though `"leetcode"`
contains `"code"` near its end, it is not a prefix.

### Example 3

**Input:**

``` text
words = ["apple", "app", "application", "banana"]
pref = "app"
```

**Output:**

``` text
3
```

**Explanation:**

`"apple"`, `"app"`, and `"application"` all start with `"app"`.
`"banana"` does not.

## Java Solution

``` java
class Solution {
    public int prefixCount(String[] words, String pref) {
        int count = 0;

        for (String word : words) {
            if (word.length() >= pref.length()) {
                boolean isMatch = true;

                for (int j = 0; j < pref.length(); j++) {
                    if (word.charAt(j) != pref.charAt(j)) {
                        isMatch = false;
                        break;
                    }
                }

                if (isMatch) {
                    count++;
                }
            }
        }

        return count;
    }
}
```

## Code Explanation

1.  **Initialize `count`:**

    ``` java
    int count = 0;
    ```

    This variable stores the number of words that start with the given
    prefix.

2.  **Visit every word:**

    ``` java
    for (String word : words)
    ```

    The enhanced `for` loop checks each word in the array.

3.  **Check the word length:**

    ``` java
    if (word.length() >= pref.length())
    ```

    A word shorter than the prefix cannot start with that prefix. So,
    compare characters only when the word is long enough.

4.  **Assume the prefix matches:**

    ``` java
    boolean isMatch = true;
    ```

    Initially, assume the word matches. We will change this to `false`
    if any character differs.

5.  **Compare characters:**

    ``` java
    for (int j = 0; j < pref.length(); j++) {
        if (word.charAt(j) != pref.charAt(j)) {
            isMatch = false;
            break;
        }
    }
    ```

    Compare each character of the prefix with the character at the same
    position in the word. If a mismatch is found, the word is not a
    match, so set `isMatch` to `false` and stop checking that word.

6.  **Increase the count:**

    ``` java
    if (isMatch) {
        count++;
    }
    ```

    If all prefix characters match, increment the count.

7.  **Return the result:**

    ``` java
    return count;
    ```

    After checking every word, return the total number of matching
    words.

## Dry Run

Consider:

``` text
words = ["apple", "app", "banana"]
pref = "app"
```

  Word         Character comparison        Match?     Count
  ------------ --------------------------- -------- -------
  `"apple"`    `a = a`, `p = p`, `p = p`   Yes            1
  `"app"`      `a = a`, `p = p`, `p = p`   Yes            2
  `"banana"`   `b != a` at index 0         No             2

**Final output:** `2`

## Complexity Analysis

Let:

-   `N` be the number of words in the array.
-   `P` be the length of the prefix.

**Time Complexity: `O(N × P)`**

In the worst case, every word is long enough and all `P` prefix
characters are compared. This happens for each of the `N` words.

**Space Complexity: `O(1)`**

Only a few extra variables (`count`, `word`, `isMatch`, and `j`) are
used. No additional data structure is created.

## Key Takeaway

To check whether a word starts with a prefix, compare the prefix
characters with the word's characters from index `0` onward. The word is
a match only if every character in the prefix matches.

**Java shortcut:** Java provides the built-in method
`word.startsWith(pref)`, which performs this prefix check directly. The
same solution can be shortened using it:

``` java
class Solution {
    public int prefixCount(String[] words, String pref) {
        int count = 0;

        for (String word : words) {
            if (word.startsWith(pref)) {
                count++;
            }
        }

        return count;
    }
}
```
