# LeetCode: Find Words Containing Character

## Problem Idea

Given an array of strings `words` and a character `x`, return a list of indices of the words that contain `x`.

The indices should be returned in the same order as the words appear in the array.

This file compares two approaches:

1. **My solution:** Loop through each character of every word using `charAt()`.
2. **Shorter alternative:** Use Java's built-in `String.indexOf()` method.

---

## Example 1

**Input**
```text
words = ["leet", "code"]
x = "e"
```

**Walkthrough**

- `"leet"` contains `e`, so add index `0`.
- `"code"` contains `e`, so add index `1`.

**Output**
```text
[0, 1]
```

## Example 2

**Input**
```text
words = ["abc", "bcd", "aaaa", "cbc"]
x = "a"
```

**Walkthrough**

- `"abc"` contains `a` → add index `0`.
- `"bcd"` does not contain `a` → skip.
- `"aaaa"` contains `a` → add index `2`.
- `"cbc"` does not contain `a` → skip.

**Output**
```text
[0, 2]
```

## Example 3

**Input**
```text
words = ["hello", "world", "java"]
x = "z"
```

None of the words contains `z`.

**Output**
```text
[]
```

## Approach 1: My Solution — Character-by-Character Search

### Java Code

```java
class Solution {
    public List<Integer> findWordsContaining(String[] words, char x) {
        List<Integer> list = new ArrayList<>();

        for (int i = 0; i < words.length; i++) {
            String word = words[i];

            for (int j = 0; j < word.length(); j++) {
                if (word.charAt(j) == x) {
                    list.add(i);
                    break;
                }
            }
        }

        return list;
    }
}
```

> Remember to import `java.util.List` and `java.util.ArrayList` if your environment does not provide them automatically.

### How It Works

1. Create an empty list to store matching indices.
2. Loop through each word using `i`.
3. Loop through the characters of the current word using `j`.
4. If `word.charAt(j) == x`, add the word's index `i` to the list.
5. Use `break` so the same index is not added more than once, even if the word contains `x` multiple times.
6. Return the list.

### Dry Run

For `words = ["abc", "bcd", "aaaa", "cbc"]` and `x = 'a'`:

| Index `i` | Word | Does it contain `'a'`? | Action | List after checking |
|---:|---|---|---|---|
| 0 | `"abc"` | Yes | Add `0` and break | `[0]` |
| 1 | `"bcd"` | No | Do not add | `[0]` |
| 2 | `"aaaa"` | Yes | Add `2` and break | `[0, 2]` |
| 3 | `"cbc"` | No | Do not add | `[0, 2]` |

**Output:** `[0, 2]`

## Approach 2: Using `indexOf()`

### Java Code

```java
class Solution {
    public List<Integer> findWordsContaining(String[] words, char x) {
        List<Integer> list = new ArrayList<>();

        for (int i = 0; i < words.length; i++) {
            if (words[i].indexOf(x) != -1) {
                list.add(i);
            }
        }

        return list;
    }
}
```

### How `indexOf()` Works

Java's `indexOf(x)` returns:

- The index of the **first occurrence** of `x` if it exists.
- `-1` if `x` does not occur in the string.

For example:

```java
"hello".indexOf('e')  // returns 1
"hello".indexOf('z')  // returns -1
"aaaa".indexOf('a')   // returns 0
```

Therefore:

```java
if (words[i].indexOf(x) != -1)
```

means: **If the current word contains `x`, add its index to the result list.**

This method does not need an explicit inner loop in your code. Java still searches the string internally.

## Complexity Analysis

Let:
- `n` = number of words.
- `L` = maximum length of a word.
- `T` = total number of characters across all words.

| Approach | Time Complexity | Extra Space (excluding result) |
|---|---|---|
| Character-by-character loop | `O(T)`, at most `O(n × L)` | `O(1)` |
| `indexOf()` | `O(T)` in the worst case, at most `O(n × L)` | `O(1)` auxiliary space at the algorithm level |

Both approaches have the same worst-case time complexity: **`O(T)`**. The `indexOf()` version is shorter and easier to read, but it is not necessarily asymptotically faster; Java still has to search each word.

The result list can contain up to `n` indices, so its space usage is **`O(n)`**.

## Key Takeaways

- Your solution is correct and demonstrates nested-loop string traversal.
- `break` is important: it prevents adding the same word index more than once.
- `indexOf(x) != -1` is a concise way to check whether a string contains a character.
- The shorter version improves readability, but both approaches are **`O(T)`** in the worst case.
