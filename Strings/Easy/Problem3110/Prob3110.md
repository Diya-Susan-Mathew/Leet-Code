# LeetCode 3110: Score of a String

## Problem

Given a string `s`, calculate its score by adding the absolute difference between the ASCII values of every pair of adjacent characters.

For each index `i`, calculate:

`|s.charAt(i) - s.charAt(i + 1)|`

Return the total score.

## Java Solution

```java
class Solution {
    public int scoreOfString(String s) {
        int value;
        int sum = 0;

        for (int i = 0; i < s.length() - 1; i++) {
            if (s.charAt(i) > s.charAt(i + 1)) {
                value = (int) s.charAt(i) - (int) s.charAt(i + 1);
            } else {
                value = (int) s.charAt(i + 1) - (int) s.charAt(i);
            }

            sum += value;
        }

        return sum;
    }
}
```

## Explanation

### 1. Initialize variables

```java
int value;
int sum = 0;
```

- `value` stores the absolute difference between two adjacent characters.
- `sum` stores the total score.

### 2. Loop through adjacent characters

```java
for (int i = 0; i < s.length() - 1; i++)
```

The loop stops at `s.length() - 2` because each character is compared with the next character, `s.charAt(i + 1)`.

### 3. Find the absolute difference

```java
if (s.charAt(i) > s.charAt(i + 1)) {
    value = (int) s.charAt(i) - (int) s.charAt(i + 1);
} else {
    value = (int) s.charAt(i + 1) - (int) s.charAt(i);
}
```

Characters have numeric values. For the lowercase English letters in this problem, their ASCII values can be used.

- If the current character has a greater value, subtract the next character from it.
- Otherwise, subtract the current character from the next character.

This ensures `value` is never negative, so it calculates the absolute difference.

### 4. Add each difference to the total

```java
sum += value;
```

Adds the difference for the current pair to `sum`.

### 5. Return the score

```java
return sum;
```

Returns the sum of all adjacent-character differences.

## Example Walkthrough

Input:

```text
s = "hello"
```

| Adjacent characters | Character values | Absolute difference |
|---|---:|---:|
| `h`, `e` | 104, 101 | 3 |
| `e`, `l` | 101, 108 | 7 |
| `l`, `l` | 108, 108 | 0 |
| `l`, `o` | 108, 111 | 3 |

Total score: `3 + 7 + 0 + 3 = 13`

Output:

```text
13
```

## Complexity Analysis

- **Time complexity:** `O(n)`, where `n` is the length of the string. Each adjacent pair is checked once.
- **Auxiliary space complexity:** `O(1)`, because only a few variables are used.

## A Shorter Alternative

Java's `Math.abs()` calculates the absolute value, so the `if-else` can be simplified:

```java
class Solution {
    public int scoreOfString(String s) {
        int sum = 0;

        for (int i = 0; i < s.length() - 1; i++) {
            sum += Math.abs(s.charAt(i) - s.charAt(i + 1));
        }

        return sum;
    }
}
```

## Key Idea to Remember

Compare every character with the character immediately after it, calculate the absolute difference, and add all differences together.
