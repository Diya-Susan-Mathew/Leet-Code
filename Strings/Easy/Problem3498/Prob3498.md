# LeetCode 3498: Reverse Degree of a String

## Problem

For each lowercase English letter in a string `s`:

1. Find its reverse alphabet position: `a -> 26`, `b -> 25`, ..., `z -> 1`.
2. Multiply that value by the character's **1-based index** in the string.
3. Add all products to get the reverse degree.

## Approach 1: My Solution

### Java Code

```java
class Solution {
    public int reverseDegree(String s) {
        int index_val, val, sum = 0;

        for (int i = 0; i < s.length(); i++) {
            index_val = Math.abs(122 - (int) s.charAt(i)) + 1;
            val = (i + 1) * index_val;
            sum += val;
        }

        return sum;
    }
}
```

### Explanation

- `index_val` stores the reverse alphabet position of the current character.
- `val` stores that reverse position multiplied by the character's 1-based string index.
- `sum` stores the total.

The expression

```java
index_val = Math.abs(122 - (int) s.charAt(i)) + 1;
```

uses `122`, the character value of `'z'`. For lowercase letters, this calculates `122 - character value + 1`.

For example, `'c'` has character value `99`, so its reverse position is `Math.abs(122 - 99) + 1 = 24`.

Since lowercase English letters are always at or before `'z'`, `Math.abs()` is unnecessary here.

Then:

```java
val = (i + 1) * index_val;
sum += val;
```

The expression `i + 1` gives the 1-based position in the string, and the contribution is added to `sum`.

## Approach 2: Alternative Solution Using `'a'`

### Java Code

```java
class Solution {
    public int reverseDegree(String s) {
        int sum = 0;

        for (int i = 0; i < s.length(); i++) {
            // Reverse alphabet position: 'a' -> 26, ..., 'z' -> 1
            int reverseValue = 26 - (s.charAt(i) - 'a');

            // Multiply by the 1-based string index
            sum += (i + 1) * reverseValue;
        }

        return sum;
    }
}
```

### Explanation

The expression

```java
26 - (s.charAt(i) - 'a')
```

calculates the reverse alphabet position.

Subtracting `'a'` gives the zero-based alphabet position:

- `'a' - 'a' = 0`
- `'b' - 'a' = 1`
- `'c' - 'a' = 2`
- ...
- `'z' - 'a' = 25`

Subtracting that value from `26` reverses the positions.

| Letter | `letter - 'a'` | Reverse value |
|---|---:|---:|
| `a` | 0 | 26 |
| `b` | 1 | 25 |
| `c` | 2 | 24 |
| `x` | 23 | 3 |
| `y` | 24 | 2 |
| `z` | 25 | 1 |

The line

```java
sum += (i + 1) * reverseValue;
```

multiplies the reverse alphabet position by the 1-based string position and adds it to the total.

## Example Walkthrough

Input:

```text
s = "abc"
```

| Index `i` | Letter | Reverse value | 1-based position | Contribution |
|---:|---|---:|---:|---:|
| 0 | `a` | 26 | 1 | 1 × 26 = 26 |
| 1 | `b` | 25 | 2 | 2 × 25 = 50 |
| 2 | `c` | 24 | 3 | 3 × 24 = 72 |

Total: `26 + 50 + 72 = 148`

Output:

```text
148
```

## Complexity Analysis

Both approaches have:

- **Time complexity:** `O(n)`, where `n` is the length of the string. Each character is processed once.
- **Auxiliary space complexity:** `O(1)`, because only a fixed number of variables are used.

## Comparison

| Feature | Your solution | Alternative solution |
|---|---|---|
| Reverse position formula | `Math.abs(122 - (int) s.charAt(i)) + 1` | `26 - (s.charAt(i) - 'a')` |
| Uses `Math.abs()` | Yes, but it is unnecessary for lowercase letters | No |
| Readability | Uses the numeric character value of `'z'` | Expresses the alphabet position directly |
| Time complexity | `O(n)` | `O(n)` |
| Auxiliary space | `O(1)` | `O(1)` |

Both solutions return the same result for lowercase English letters. The second formula is generally clearer because it directly calculates the reverse alphabet position.

## Key Idea to Remember

Use `26 - (s.charAt(i) - 'a')` to calculate the reverse alphabet position, multiply it by `i + 1`, and add it to the running total.
