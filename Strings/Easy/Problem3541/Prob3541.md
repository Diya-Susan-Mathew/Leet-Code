# LeetCode 3541 - Find Most Frequent Vowel and Consonant

## Problem Description

You are given a string `s` containing lowercase English letters.

Your task is to:

1. Find the vowel that appears the most times in the string.
2. Find the consonant that appears the most times in the string.
3. Return the **sum of their frequencies**.

The vowels are `a`, `e`, `i`, `o`, and `u`. All other English lowercase letters are consonants.

**Important:** You need to find the maximum frequency in each category, not the total number of vowels and consonants.

If a category has no characters in the string, its maximum frequency is `0`.

## Example 1

**Input:**
```text
s = "successes"
```

**Output:**
```text
6
```

### Explanation

The string `"successes"` contains the following characters:

| Character | Frequency | Category |
|---|---:|---|
| s | 4 | Consonant |
| u | 1 | Vowel |
| c | 2 | Consonant |
| e | 2 | Vowel |

The remaining letters do not appear in the string, so their frequencies are zero.

**Step 1: Find the maximum vowel frequency.**

- `u` appears 1 time.
- `e` appears 2 times.

Therefore, `maxVowel = 2`.

**Step 2: Find the maximum consonant frequency.**

- `s` appears 4 times.
- `c` appears 2 times.

Therefore, `maxConso = 4`.

**Step 3: Add the two maximum frequencies.**

```text
Answer = maxVowel + maxConso
       = 2 + 4
       = 6
```

Therefore, the answer is `6`.

## Example 2

**Input:**
```text
s = "aeiou"
```

**Output:**
```text
1
```

### Explanation

Every character is a vowel and appears exactly once.

- Maximum vowel frequency = `1`
- There are no consonants, so maximum consonant frequency = `0`

```text
Answer = 1 + 0 = 1
```

## Approach: Frequency Array

We use an integer array of size 26 to count how many times each lowercase English letter appears.

### Algorithm

1. Create an integer array `freq` of size 26, initialized to zero.
2. Traverse the string and count the occurrences of each character using `freq[ch - 'a']++`.
3. Iterate through all 26 letters.
4. If the letter is a vowel, update `maxVowel` using `Math.max()`.
5. Otherwise, update `maxConso` using `Math.max()`.
6. Return `maxVowel + maxConso`.

## Java Solution

```java
class Solution {
    public int maxFreqSum(String s) {
        int[] freq = new int[26];

        for (int i = 0; i < s.length(); i++) {
            char ch = s.charAt(i);

            if (ch >= 'a' && ch <= 'z') {
                freq[ch - 'a']++;
            }
        }

        int maxVowel = 0;
        int maxConso = 0;

        for (int i = 0; i < 26; i++) {
            char ch = (char) ('a' + i);

            if (ch == 'a' || ch == 'e' || ch == 'i'
                    || ch == 'o' || ch == 'u') {
                maxVowel = Math.max(maxVowel, freq[i]);
            } else {
                maxConso = Math.max(maxConso, freq[i]);
            }
        }

        return maxVowel + maxConso;
    }
}
```

## Complexity Analysis

- **Time Complexity:** \(O(n)\), where `n` is the length of the string. We traverse the string and then check 26 letters.
- **Space Complexity:** \(O(1)\), because the frequency array always has a fixed size of 26.
