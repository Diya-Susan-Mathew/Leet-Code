# Reverse Prefix of a String

## Problem

Given a string `s` and an integer `k`, reverse the first `k` characters
of the string while keeping the remaining characters in their original
order.

## Java Solution

``` java
class Solution {
    public String reversePrefix(String s, int k) {
        StringBuilder sb = new StringBuilder();

        // Append the first k characters in reverse order
        for (int i = k - 1; i >= 0; i--) {
            sb.append(s.charAt(i));
        }

        // Append the remaining characters without changing their order
        sb.append(s, k, s.length());

        return sb.toString();
    }
}
```

## Explanation

The solution uses a `StringBuilder` to construct the resulting string
efficiently.

1.  Create an empty `StringBuilder`.
2.  Start a loop at index `k - 1` and move backwards until index `0`.
    -   This appends the first `k` characters in reverse order.
3.  Use `sb.append(s, k, s.length())` to append the substring starting
    at index `k` and ending just before `s.length()`.
    -   These remaining characters retain their original order.
4.  Convert the `StringBuilder` into a string using `toString()` and
    return it.

## Example 1

**Input:**

``` text
s = "abcdef", k = 3
```

**Step-by-step:**

-   The first `k = 3` characters are `"abc"`.
-   Reverse them to get `"cba"`.
-   The remaining substring is `"def"`.
-   Combine both parts: `"cba" + "def"`.

**Output:**

``` text
"cbadef"
```

## Example 2

**Input:**

``` text
s = "hello", k = 2
```

**Step-by-step:**

-   The first two characters are `"he"`.
-   Reverse them to get `"eh"`.
-   The remaining substring is `"llo"`.
-   Combine both parts: `"eh" + "llo"`.

**Output:**

``` text
"ehllo"
```

## Complexity Analysis

Let `n` be the length of the string.

-   **Time Complexity: O(n)** --- The loop processes `k` characters, and
    appending the remaining characters processes `n - k` characters.
    Together, this takes O(n) time.
-   **Space Complexity: O(n)** --- The `StringBuilder` stores the
    resulting string, which contains `n` characters.

## Important Java Method

``` java
sb.append(s, k, s.length());
```

This overloaded `append()` method appends a character sequence from the
specified start index (inclusive) to end index (exclusive).

For example:

``` java
String s = "abcdef";
sb.append(s, 3, 6); // Appends "def"
```

**Note:** This solution assumes `1 <= k <= s.length()`.
